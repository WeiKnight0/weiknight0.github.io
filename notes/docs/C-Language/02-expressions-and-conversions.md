# C Expressions and Conversions 运算符、表达式与类型转换

## 1. 优先级不等于求值顺序

优先级决定表达式如何结合，结合性只在同一优先级出现多个运算符时决定分组。它们**不**规定子表达式先后求值顺序。

```c
int x;

x = 1 + 2 * 3;       /* 等价于 x = 1 + (2 * 3) */
x = 10 - 3 - 2;      /* 等价于 x = (10 - 3) - 2 */
```

常用记忆顺序：后缀 `()` `[]` `.` `->`、一元运算、乘除模、加减、关系、相等、位运算、逻辑、条件 `?:`、赋值、逗号。真正不确定时加括号，不要靠背表赌题。

## 2. 整数除法、取模与自增自减

```c
#include <stdio.h>

int main(void)
{
    int a;
    int b;

    a = 7 / 2;
    b = 7 % 2;
    printf("%d %d\n", a, b);
    return 0;
}
```

输出为 `3 1`。两个整数相除结果仍为整数；只要有一个操作数是浮点类型，才进行浮点除法。

- `++i`：先加 1，再取值。
- `i++`：先取旧值，表达式结束前再加 1。
- 不要在同一表达式中既修改变量又在没有明确时序处读取它，例如 `i = i++ + 1;`；这类表达式行为未定义，不能用于推题。

## 3. 逻辑运算与短路

逻辑真为 `1`，假为 `0`。`&&` 与 `||` 从左到右求值且短路；位运算 `&`、`|`、`^` 不短路。

```c
if (ptr != NULL && ptr->value > 0) {
    /* 只有 ptr 非空时才访问 value */
}
```

这里不能写成 `ptr->value > 0 && ptr != NULL`，因为左边会先解引用空指针。

## 4. 隐式转换与显式强制转换

赋值、运算和函数调用都可能发生转换。考试中最常见的是整型提升与有符号/无符号混合。

```c
#include <stdio.h>

int main(void)
{
    int a;
    int b;
    double average;

    a = 5;
    b = 2;
    average = (double)a / b;
    printf("%.1f\n", average);
    return 0;
}
```

若没有 `(double)`，`a / b` 会先得到整数 `2`，之后才被赋给 `double`。强制转换只能改变当前表达式的计算方式，不能修复溢出、越界或错误的对象类型。

## 5. 条件、赋值与逗号表达式

- `condition ? a : b`：只求值其中一个分支；两个分支的类型需要能协调。
- 赋值表达式有值，`if (x = 0)` 合法但通常是笔误；它给 `x` 赋 0，条件为假。比较应写 `x == 0`。
- 逗号运算符从左到右求值，整体值为右操作数；注意它与函数实参之间的逗号不同。

```c
int i;
int value;

i = 1;
value = (i = i + 1, i * 3);  /* value 为 6 */
```

## 6. 位运算的边界

`&`、`|`、`^`、`~`、`<<`、`>>` 用于整数位模式。位移位数不能为负，也不能大于等于类型宽度；对负数左移、带符号右移的细节不应凭直觉猜测。涉及掩码时优先使用无符号常量，例如 `1U << bit`。

## 考试检查表

- 先确认操作数类型，再计算表达式，不要只看变量最终接收的类型。
- `=`、`==`，`&`、`&&`，`|`、`||` 是高频改错点。
- 遇到多个 `++`、函数调用或赋值混在一行，先判断是否有未定义行为；有则不能推出唯一结果。
