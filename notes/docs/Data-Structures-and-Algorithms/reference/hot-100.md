## [136. 只出现一次的数字](https://leetcode.cn/problems/single-number/)

**题目描述：**

给定一个**非空**整数数组 `nums`。除某一个元素只出现一次外，其余每个元素都恰好出现两次；找出那个只出现一次的元素。

要求算法的时间复杂度为 $O(n)$，且只能使用 $O(1)$ 的额外空间。因此不能依赖排序，也不能使用哈希表记录所有出现次数。

**输入：**

第一行输入整数 `n`，第二行输入 `n` 个整数。保证 `1 <= n <= 3 * 10^4`，且除一个元素外，其余元素均出现两次。

**输出：**

输出只出现一次的整数。

**示例：**

```text
输入：
5
4 1 2 1 2

输出：
4
```

**思路：**

使用按位异或 `^`。它满足：

- `x ^ x = 0`：相同数字会抵消；
- `x ^ 0 = x`；
- 异或满足交换律和结合律，计算顺序不会影响结果。

因此把所有元素异或在一起，所有成对元素都会变为 `0`，最后只剩下只出现一次的元素。

**代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    int answer = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        answer ^= x;
    }

    cout << answer << '\n';
    return 0;
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

## [169. 多数元素](https://leetcode.cn/problems/majority-element/)

**题目描述：**

给定一个大小为 `n` 的非空整数数组 `nums`，其中一定存在一个多数元素。多数元素指在数组中出现次数**严格大于** $\lfloor n / 2 \rfloor$ 的元素。返回该多数元素。

题目保证答案存在。进阶要求是在 $O(n)$ 时间和 $O(1)$ 额外空间内完成，而不是排序后直接取中间元素或用哈希表计数。

**输入：**

第一行输入整数 `n`，第二行输入 `n` 个整数。保证 `1 <= n <= 5 * 10^4`，且存在多数元素。

**输出：**

输出多数元素。

**示例：**

```text
输入：
7
2 2 1 1 1 2 2

输出：
2
```

**思路：**

使用 Boyer–Moore 投票算法，维护候选值 `candidate` 和票数 `count`：

1. 当 `count == 0` 时，把当前数设为新候选；
2. 当前数等于候选，票数加一；否则票数减一。

这相当于不断删除一对不同的元素。多数元素的出现次数比其余所有元素总数还多，所以无论如何两两抵消，它都不可能被完全删掉；最终候选必然是多数元素。

若题目**没有**保证多数元素存在，投票结束后还必须再扫描一次验证候选出现次数。

**代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    int candidate = 0;
    int count = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;

        if (count == 0) {
            candidate = x;
        }
        count += (x == candidate) ? 1 : -1;
    }

    cout << candidate << '\n';
    return 0;
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

## [75. 颜色分类](https://leetcode.cn/problems/sort-colors/)

**题目描述：**

给定一个长度为 `n` 的数组 `nums`，数组中只包含 `0`、`1`、`2` 三种整数，分别代表红、白、蓝三种颜色。要求**原地**重排数组，使相同颜色相邻，且颜色顺序为 `0`、`1`、`2`。

不允许调用内置排序函数。进阶目标是只扫描数组一次，并使用常数额外空间。

**输入：**

第一行输入整数 `n`，第二行输入 `n` 个整数；每个整数均为 `0`、`1` 或 `2`，且 `1 <= n <= 300`。

**输出：**

输出排序后的数组。

**示例：**

```text
输入：
6
2 0 2 1 1 0

输出：
0 0 1 1 2 2
```

**思路：**

采用题解中的线性插入排序思路。扫描到下标 `i` 时，维护已经处理的前缀为三段：

- `[0, p0)` 都是 `0`；
- `[p0, p1)` 都是 `1`；
- `[p1, i)` 都是 `2`。

因此新元素不需要移动一整段：

- 遇到 `2`，它天然位于已处理前缀的最后，保持不动；
- 遇到 `1`，与 `p1` 位置交换，把它插入到所有 `2` 之前，再令 `p1++`；
- 遇到 `0`，先与 `p0` 位置交换，把 `0` 插到最前方。若 `p0 < p1`，此时被换到 `i` 的是 `1`，还要再与 `p1` 位置交换，把该 `1` 放回 `1` 区末尾。最后 `p0`、`p1` 都右移。

每个元素只进行常数次交换，循环不变量始终成立，所以这是一趟 $O(n)$ 的原地插入过程。

**代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int& x : nums) cin >> x;

    int p0 = 0; // 下一个 0 应插入的位置
    int p1 = 0; // 下一个 1 应插入的位置

    for (int i = 0; i < n; i++) {
        if (nums[i] == 0) {
            swap(nums[i], nums[p0]);
            if (p0 < p1) {
                swap(nums[i], nums[p1]);
            }
            p0++;
            p1++;
        } else if (nums[i] == 1) {
            swap(nums[i], nums[p1]);
            p1++;
        }
    }

    for (int x : nums) cout << x << ' ';
    cout << '\n';
    return 0;
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。关键边界是 `p0 < p1`：说明前缀中存在 `1`，处理 `0` 的第一次交换会把一个 `1` 带到末尾，必须进行第二次交换。

## [31. 下一个排列](https://leetcode.cn/problems/next-permutation/)

**题目描述：**

一个整数数组的排列，是将数组全部元素按某种线性顺序排列的结果。数组的**下一个排列**，指所有排列按字典序从小到大排列时，紧邻当前排列之后的那个排列。

若存在比当前排列更大的排列，必须得到其中字典序最小的一个；若当前排列已经是最大排列，则将数组原地重排为字典序最小的升序排列。要求只能使用常数额外空间原地修改数组。

例如，`[1,2,3]` 的下一个排列是 `[1,3,2]`；`[2,3,1]` 的下一个排列是 `[3,1,2]`；`[3,2,1]` 没有更大的排列，结果为 `[1,2,3]`。

**输入：**

第一行输入整数 `n`，第二行输入 `n` 个整数。保证 `1 <= n <= 100`，且 `0 <= nums[i] <= 100`。

**输出：**

输出原地修改后的下一个排列。

**示例：**

```text
输入：
3
1 1 5

输出：
1 5 1
```

**思路：**

从右往左处理，因为右侧后缀对字典序的影响最小：

1. 找最靠右的 `i`，满足 `nums[i] < nums[i + 1]`。其右侧是非递增后缀，已经是这组数能构成的最大排列。
2. 若存在这样的 `i`，从右往左找第一个大于 `nums[i]` 的 `j`，交换二者。这样让更高位刚好变大一点。
3. 将 `i + 1` 开始的后缀反转。该后缀原本非递增，反转后成为最小的升序后缀，使整体成为“刚好更大”的排列。

若找不到 `i`，说明整个数组非递增，直接反转整个数组即可。

**代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int& x : nums) cin >> x;

    int i = n - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) {
        i--;
    }

    if (i >= 0) {
        int j = n - 1;
        while (nums[j] <= nums[i]) {
            j--;
        }
        swap(nums[i], nums[j]);
    }

    reverse(nums.begin() + i + 1, nums.end());

    for (int x : nums) cout << x << ' ';
    cout << '\n';
    return 0;
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

## [287. 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number/)

**题目描述：**

给定一个长度为 `n + 1` 的整数数组 `nums`，其中每个值都在闭区间 `[1, n]` 内。数组中恰好只有一个整数重复出现，它可能出现两次或更多次，其余整数均只出现一次。返回这个重复整数。

要求不能修改原数组，且只能使用 $O(1)$ 的额外空间。由抽屉原理可知：将 `n + 1` 个数放入只有 `n` 个取值的位置，至少存在一个重复值。

**输入：**

第一行输入整数 `n`，第二行输入 `n + 1` 个整数。保证 `1 <= n <= 10^5`，每个数在 `[1, n]` 内，且仅有一个值重复。

**输出：**

输出重复的整数。

**示例：**

```text
输入：
4
1 3 4 2 2

输出：
2
```

**思路：**

把下标看成链表节点，并定义 `next(i) = nums[i]`。因为所有 `nums[i]` 都在 `[1, n]` 中，从 `nums[0]` 出发会一直落在合法下标范围内。有限节点上不断沿 `next` 前进，必然进入一个环。

重复值正是环的入口：两个不同下标指向同一个数时，链表路径在该值处汇合并形成环。于是可用 Floyd 判环算法：

1. 慢指针每次走一步，快指针每次走两步，它们一定会在环内相遇；
2. 再令一个指针从起点出发，另一个从相遇点出发，二者都每次走一步；再次相遇的位置就是环入口，也就是重复数。

该方法不修改数组，也不需要哈希表。

**代码：**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> nums(n + 1);
    for (int& x : nums) cin >> x;

    int slow = nums[0];
    int fast = nums[0];
    do {
        slow = nums[slow];
        fast = nums[nums[fast]];
    } while (slow != fast);

    int finder = nums[0];
    while (finder != slow) {
        finder = nums[finder];
        slow = nums[slow];
    }

    cout << finder << '\n';
    return 0;
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。注意数组长度是 `n + 1`，而值域是 `[1, n]`；若修改数组或用集合，虽然能找到重复数，却不满足原题进阶限制。
