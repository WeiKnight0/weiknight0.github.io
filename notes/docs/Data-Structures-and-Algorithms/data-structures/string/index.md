# 串

串是由零个或多个字符组成的有限序列，记作 $S='a_1a_2\cdots a_n'$。$n$ 是串长，$n=0$ 时称为空串。串中任意个连续字符组成子串。

## 基本操作

- 赋值、复制、清空和判空
- 求串长与比较两个串
- 串连接与求子串
- 定位和替换子串

串的比较通常按字典序进行：从左到右比较第一个不同字符；若较短串是较长串的前缀，则较短串更小。

## 存储结构

### 定长顺序存储

用固定长度数组保存字符。操作结果超过容量时只能截断或报错，适合串长有明确上限的场景。

### 堆分配顺序存储

在堆上动态申请连续空间，同时保存首地址和当前串长。它兼具顺序存储的随机访问能力与动态扩容能力。

### 块链存储

将字符分成多个定长字符块，每个节点保存一块字符和后继指针。块越小，指针占用比例越高；块越大，末尾块的内部碎片越多。

## 模式匹配

模式匹配要在主串 $S$ 中查找模式串 $T$ 第一次出现的位置。朴素匹配在失配后将主串起点后移一位，然后从模式串首字符重新比较，最坏时间复杂度为 $O(nm)$。

KMP 只移动模式串，主串指针不回退。具体的 `next` 数组、改进 `nextval` 与实现详见 [KMP 字符串匹配](../../algorithms/string/kmp.md)。
