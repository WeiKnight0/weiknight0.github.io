# 图

图 $G=(V,E)$ 由顶点集 $V$ 和边集 $E$ 组成。顶点集不能为空，边集可以为空。$|V|$ 表示顶点数，$|E|$ 表示边数。

## 图的类型

- **无向图**：每条边没有方向，记作 $(u,v)$。
- **有向图**：每条边有方向，记作 $\langle u,v\rangle$，$u$ 是弧尾，$v$ 是弧头。
- **简单图**：不存在重复边和顶点到自身的环。
- **多重图**：允许两个顶点之间存在多条边，或允许自环。
- **带权图**：每条边关联一个权值。
- **子图**：顶点集和边集分别是原图顶点集和边集的子集，且边的端点仍在子图中。

含 $n$ 个顶点的无向完全图有 $n(n-1)/2$ 条边；有向完全图有 $n(n-1)$ 条弧。

## 度

无向图中，顶点 $v$ 的度 $TD(v)$ 是与它关联的边数，所有顶点度数之和为：

$$\sum_{v\in V}TD(v)=2|E|$$

有向图中，入度 $ID(v)$ 是以 $v$ 为弧头的弧数，出度 $OD(v)$ 是以 $v$ 为弧尾的弧数。所有顶点的入度之和与出度之和都等于 $|E|$。

## 路径与连通性

- **路径**：顶点与边交替组成的序列；路径长度是其中边的数量或权值之和。
- **回路**：第一个顶点和最后一个顶点相同的路径。
- **简单路径**：顶点不重复出现的路径。
- **距离**：两个顶点之间最短路径的长度；不可达时为无穷。
- **连通图**：无向图中任意两个顶点都有路径。
- **强连通图**：有向图中任意两个顶点都能沿有向路径相互到达。

无向图的极大连通子图称为连通分量，有向图的极大强连通子图称为强连通分量。连通无向图的极小连通子图是生成树，含全部 $n$ 个顶点和 $n-1$ 条边。

## 存储结构

### 邻接矩阵

用 $|V|\times|V|$ 的矩阵表示边。无权图中，$A[i][j]=1$ 表示存在边；带权图中保存边权，不存在的边用无穷表示。

- 空间复杂度为 $O(|V|^2)$，适合稠密图。
- 判断两个顶点是否相邻只需 $O(1)$。
- 无向图的邻接矩阵关于主对角线对称，顶点度是对应行的元素之和。
- 有向图中第 $i$ 行表示顶点 $i$ 的出边，第 $i$ 列表示入边。

### 邻接表

为每个顶点建立一条边链表。顶点表节点保存顶点信息和边链表首指针，边节点保存邻接顶点编号、边权和后继指针。

- 空间复杂度为 $O(|V|+|E|)$，适合稀疏图。
- 无向图的每条边在两个端点的链表中各出现一次。
- 有向图的邻接表容易求出度，求入度需要遍历全部边；逆邻接表则相反。

邻接表中边节点的顺序不唯一，因此同一个图的邻接表表示不唯一。

### 十字链表

十字链表用于有向图。每条弧只保存一次，弧节点同时链入弧尾的出边表和弧头的入边表，因而既方便查找出边，也方便查找入边。

### 邻接多重表

邻接多重表用于无向图。每条边只保存一次，边节点同时链入两个端点的边表，适合需要频繁删除边或查找与顶点关联的所有边的场景。
