# Array and Matrix 数组与矩阵

## 数组的存储

数组由类型相同的数据元素构成，各元素按固定顺序存放在连续地址中。一维数组 $A[0 \ldots n-1]$ 的首地址为 $LOC(A)$，每个元素占 $d$ 个字节，则：

$$
LOC(A[i]) = LOC(A) + i \times d
$$

二维数组在物理上仍然是一维的连续空间。对 $m$ 行 $n$ 列、下标从 $0$ 开始的数组 $A$：

- 行优先：$LOC(A[i][j]) = LOC(A) + (i \times n + j)d$
- 列优先：$LOC(A[i][j]) = LOC(A) + (j \times m + i)d$

## 对称矩阵

$n$ 阶对称矩阵满足 $a_{ij}=a_{ji}$，只需存储上三角或下三角，共有 $n(n+1)/2$ 个元素。按行优先存储下三角，对于 $i \ge j$ 且下标从 $0$ 开始：

$$
k = \frac{i(i+1)}{2} + j
$$

上三角元素可利用对称性转换为对应下三角元素。

## 三角矩阵

上三角或下三角矩阵的非常量区域共有 $n(n+1)/2$ 个元素。另外使用一个单元保存三角外部的相同常量，总共需要 $n(n+1)/2+1$ 个存储单元。

## 三对角矩阵

三对角矩阵只有主对角线及其上下相邻对角线可能非零，即 $|i-j| \le 1$。$n$ 阶三对角矩阵共有 $3n-2$ 个待存元素。

按行优先存放且下标从 $0$ 开始时，元素 $a_{ij}$ 在一维数组中的下标为：

$$
k = 2i + j
$$

## 稀疏矩阵

稀疏矩阵的非零元素远少于矩阵总元素数，继续使用二维数组会浪费大量空间。

- **三元组顺序表**：每个非零元素保存行号、列号和值。
- **十字链表**：每个非零元素同时链入所在行链表和列链表，适合频繁修改矩阵的场景。

压缩存储节省了空间，但失去了普通二维数组简单的随机存取方式。
