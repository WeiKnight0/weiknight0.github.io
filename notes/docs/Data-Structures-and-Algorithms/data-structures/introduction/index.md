# 绪论

数据结构研究数据元素之间的关系、这些关系在计算机中的表示，以及对数据可以执行的操作。

## 基本概念

- **数据**：能够输入计算机并被处理的符号集合。
- **数据元素**：数据的基本单位，一个元素可以由多个数据项组成。
- **数据对象**：具有相同性质的数据元素的集合。
- **数据类型**：一组值的集合，以及定义在这组值上的操作。
- **数据结构**：存在一种或多种特定关系的数据元素集合。

## 逻辑结构

逻辑结构只描述元素之间的关系，不关心具体存储方式。

| 结构 | 元素关系 |
| --- | --- |
| 集合 | 元素除了同属一个集合外没有其他关系 |
| 线性结构 | 除首尾外，每个元素都有唯一前驱和唯一后继 |
| 树形结构 | 元素之间是一对多关系 |
| 图状结构 | 元素之间是多对多关系 |

## 存储结构

| 存储方式 | 特点 |
| --- | --- |
| 顺序存储 | 元素占用连续地址，逻辑相邻关系由物理位置表示 |
| 链式存储 | 节点可以分散存放，用指针表示元素关系 |
| 索引存储 | 额外建立索引表，索引项保存关键字与元素地址 |
| 散列存储 | 根据关键字计算元素的存储地址 |

## 数据运算与抽象数据类型

运算的定义针对逻辑结构，运算的实现依赖具体存储结构。常见运算包括创建、销毁、查找、读取、修改、插入、删除和遍历。

抽象数据类型（ADT）只规定数据对象、元素关系和可用操作，不限定内部实现。例如栈规定 `push`、`pop` 和 `top` 等操作，但既可以用数组实现，也可以用链表实现。

## 算法

算法是对特定问题求解步骤的有限描述，应当具有有穷性、确定性、可行性、输入和输出。评价算法时通常关心正确性、可读性、健壮性与效率。
