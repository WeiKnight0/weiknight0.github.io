# Balanced Search Trees 平衡查找树

[二叉排序树](./binary-search-tree.md) 的性能取决于树高。平衡查找树通过限制树高，避免树退化为链表。

## AVL 树

AVL 树首先是二叉排序树，且任意节点左右子树高度差的绝对值不超过 $1$。节点的平衡因子定义为：

$$BF=h_{\text{left}}-h_{\text{right}}$$

平衡状态下 $BF$ 只能为 $-1$、$0$ 或 $1$。

### 旋转

插入后从新节点向根回溯，找到第一个平衡因子绝对值大于 $1$ 的节点，根据增高方向调整：

| 类型 | 新节点位置 | 调整 |
| --- | --- | --- |
| LL | 左孩子的左子树 | 右单旋 |
| RR | 右孩子的右子树 | 左单旋 |
| LR | 左孩子的右子树 | 先对左孩子左旋，再对不平衡节点右旋 |
| RL | 右孩子的左子树 | 先对右孩子右旋，再对不平衡节点左旋 |

旋转只改变局部父子关系，不改变中序序列，因此不会破坏二叉排序树性质。

插入修复通常只需调整最低不平衡子树；删除可能使多层祖先继续失衡，需要一路向根检查。

AVL 树高度为 $O(\log n)$，查找、插入和删除都能保持 $O(\log n)$。

## 红黑树

红黑树是一种较宽松的平衡二叉排序树，满足：

1. 每个节点是红色或黑色。
2. 根节点是黑色。
3. 所有空叶节点视为黑色。
4. 红色节点的父节点和孩子都是黑色。
5. 从任一节点到各个后代空叶节点的所有路径包含相同数量的黑色节点。

从某节点到后代空叶节点的任一路径上，不包含该节点本身的黑色节点数称为黑高。性质 4 保证不存在连续红色节点，性质 5 保证各分支的黑高相同。

红黑树的最长根叶路径不超过最短路径的两倍，高度不超过 $2\log_2(n+1)$，因此基本操作均为 $O(\log n)$。

插入和删除后通过变色和旋转恢复红黑性质。红黑树的平衡要求比 AVL 树宽松，通常旋转次数更少，适合插入和删除频繁的场景。

## AVL 树与红黑树

| 特性 | AVL 树 | 红黑树 |
| --- | --- | --- |
| 平衡约束 | 左右子树高度差不超过 $1$ | 使用颜色和黑高约束 |
| 查找 | 树更矮，查找常数通常更好 | 仍为 $O(\log n)$ |
| 更新 | 可能需要更多旋转 | 平衡较宽松，更适合频繁更新 |
