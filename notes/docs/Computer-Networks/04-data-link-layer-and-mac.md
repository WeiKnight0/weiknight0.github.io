# Data Link Layer 数据链路层与介质访问控制

## 一、核心概念

1. **成帧**：为实现比特传输错误的检测与纠正，接收方需从比特流中区分帧的开始和结束（帧同步 / 帧定界），包含透明传输实现，有四种核心方法。
2. **字节计数法**：通过计数字节标识帧长度，用于帧定界的成帧方法。
3. **字符填充的首尾界定法**：以特殊字符 FLAG 作为定界符，通过转义字符（ESC）处理有效载荷中出现的定界符，实现透明传输。
4. **比特填充的首尾标志法**：以 01111110（0x7E）为定界符，通过比特填充处理载荷中潜在定界符组合的成帧方法。
5. **物理层编码违例**：利用正常编码中不会出现的信号模式（如持续高 / 低电平）作为定界符的成帧方式。
6. **检错码**：在数据块中添加冗余信息，仅能让接收方判断是否出错，无法定位错误位，适用于高可靠、低误码率信道。
7. **奇偶检验**：通过增加冗余位使码字中 “1” 的个数恒为奇数或偶数的检错码，含单个奇偶校验、垂直奇偶校验、水平奇偶校验。
8. **校验和**：将数据按 16bit 分组求和得到校验和，发送方将其放入校验和字段，接收方通过重算比对检测错误，用于 TCP/IP 网络层和传输层。
9. **循环冗余校验（CRC）**：通过多项式运算生成冗余位的检错码，漏检率低，广泛应用于数据链路层，支持检测小于 r+1 比特的突发差错和奇数个比特差错。
10. **纠错码**：添加足够冗余信息，使接收方能检测并纠正错误的编码，又称前向纠错（FEC），适用于高误码率信道（如无线链路）。
11. **流量控制**：解决接收方处理速率低于发送方发送速率导致的缓冲区溢出问题，分为基于反馈和基于速率两种类型。
12. **MAC 地址**：48bit 物理地址（十六进制表示），固化在网卡 ROM，由 IEEE 分配，用于局域网内接口寻址，具有扁平性和移动性。
13. **信道分配**：解决广播通信中信道访问冲突的机制，分为静态分配、动态分配（轮流使用、随机接入）。
14. **多路复用**：静态信道分配方式，包括频分多路复用（FDM）、时分多路复用（TDM）、波分多路复用（WDM）、码分多路复用（CDM）。
15. **码分多路复用（CDM）**：各用户使用唯一正交码片序列，在同一时间、同一频带通信，通过规格化内积区分不同用户信号。
16. **受控访问**：动态信道分配方式，包括轮询法、令牌传递，需协调节点使用信道。
17. **随机访问**：动态信道分配方式，节点可随机发送数据，允许冲突并通过延迟重传恢复，包括 ALOHA、时隙 ALOHA、CSMA、CSMA/CD 等。
18. **ALOHA**：基础随机访问技术，纯 ALOHA 可随时发送数据，冲突后概率重传；时隙 ALOHA 将时间划分为时隙，仅在时隙开始时发送。
19. **CSMA**：载波监听多路访问技术，核心是 “先听后发”，分为非坚持 CSMA、1 坚持 CSMA、p 坚持 CSMA。
20. **CSMA/CD**：带冲突检测的 CSMA，核心是 “先听后发、边发边听、冲突停发、随机退避”，通过二进制指数后退法处理冲突。

## 二、简答题

1. 简述成帧的定义及核心作用。

   - 定义：为检测和纠正物理层比特传输错误，接收方从比特流中明确区分帧的开始和结束（帧同步 / 帧定界）的过程。
   - 核心作用：实现比特流到数据帧的划分，为后续错误检测与纠正提供基础，同时需解决透明传输问题（避免数据部分的定界符干扰帧划分）。

2. 字节计数法的工作原理及缺点是什么？

   - 工作原理：通过帧中的计数字节标识该帧的长度，接收方根据计数字节确定帧的边界。
   - 缺点：若计数字节出错，会破坏帧的边界，导致一连串帧的错误。

3. 字符填充的首尾界定法如何实现透明传输？接收方如何处理？

   - 发送方处理：检查有效载荷，若出现与定界符（FLAG）相同的字符，在其前插入转义字符（ESC）；若出现转义字符本身，也插入一个转义字符。
   - 接收方处理：逐个检查收到的字节，删除转义字符，恢复原始有效载荷。

4. 比特填充的首尾标志法的定界符是什么？发送方和接收方的核心处理逻辑是什么？

   - 定界符：01111110（0x7E）。
   - 发送方逻辑：检查有效载荷，若出现连续 5 个 1 比特，立即插入 1 个 0 比特。
   - 接收方逻辑：若检测到连续 5 个 1 比特，直接丢弃后面的 0 比特，恢复原始载荷。

5. 物理层编码违例的核心思想及典型应用场景是什么？

   - 核心思想：选择不会出现在正常数据部分的信号模式作为定界符。
   - 典型场景：①传统以太网、802.11 使用长前导码作为定界符；②802.5 令牌环网使用曼切斯特编码 / 差分曼切斯特编码中的持续高电平（或低电平）违例码作为定界符。

6. 数据传输中常见的错误类型有哪些？对应的发现方法是什么？

   - 差错（信道噪声导致）：发现方法为检错码。
   - 丢失（接收缓冲区溢出）：发现方法为确认 / 定时器。
   - 乱序（先发后到）：发现方法为序号。
   - 重复（多次接收相同数据）：发现方法为序号。

7. 简述奇偶检验的工作原理及局限性。

   - 工作原理：通过增加冗余位，使码字中 “1” 的个数恒为奇数（奇校验）或偶数（偶校验）。
   - 局限性：单个奇偶校验位仅能发现奇数个比特位错误，无法检测偶数个比特差错，且不能纠错。

8. 垂直奇偶校验和水平奇偶校验的编码效率如何计算？各自的漏检率特点是什么？

   - 垂直奇偶校验：编码效率 R=p/(p+1)（p 为一个信息段的比特位数），对突发错误的漏检率接近 1/2。
   - 水平奇偶校验：编码效率 R=q/(q+1)（q 为发送的字符个数），漏检率小于 1/2，可检测突发长度≤p 的所有突发错误。

9. 校验和的发送方和接收方的处理流程分别是什么？

   - 发送方流程：①将发送数据当作 16bit 为一组的序列；②每组序列相加得到校验和；③将校验和值放入校验和字段发送。
   - 接收方流程：①对接收到的数据重新计算校验和；②比较计算结果与校验和字段的值，不等则发现错误，相等则未发现错误（仍可能存在未检测到的错误）。

10. CRC 的校验能力有哪些？

    - 能检测小于 r+1 比特的突发差错；
    - 能检测出任何奇数个比特差错；
    - 生成多项式位数越多，校验能力越强。

11. 数据传输错误的纠正方法分别对应哪些错误类型？

    - 差错（信道噪声导致）：纠错码或重传。
    - 丢失（接收缓冲区溢出）：流量控制或重传。
    - 乱序（先发后到）：面向连接或重排。
    - 重复（多次接收）：丢弃重复数据。

12. 纠错码的定义及适用场景是什么？

    - 定义：发送方在数据块中加入足够冗余信息，使接收方能判断数据是否有错并纠正错误（定位出错位置）的编码，又称前向纠错（FEC）。
    - 适用场景：错误发生频繁的信道，如无线链路。

13. 流量控制的作用及分类是什么？

    - 作用：防止接收方处理速率低于发送方发送速率导致的接收缓冲区溢出，避免数据丢失。
    - 分类：①基于反馈的流量控制（接收方反馈，发送方调整速率）；②基于速率的流量控制（发送方自行限速）。

14. MAC 地址的特点及作用是什么？

    - 特点：48bit，十六进制表示（如 1A-2F-BB-76-09-AD），固化在网卡 ROM，由 IEEE 管理分配，具有唯一性、扁平性和移动性。
    - 作用：用于局域网内两个接口之间传递数据帧时的寻址，链路层交换机无链路层地址。

15. 信道静态分配（多路复用）的常见类型及核心思想是什么？

    - 常见类型：频分多路复用（FDM）、时分多路复用（TDM）、波分多路复用（WDM）、码分多路复用（CDM）。
    - 核心思想：将信道划分为小的频段、时隙或分配唯一码片序列，分配给节点互斥使用，消除冲突。

16. CDM 的核心原理及发送、接收端的处理逻辑是什么？

    - 核心原理：每个用户分配唯一的 m bit 码片序列，不同用户序列正交（规格化内积为 0）；同一用户码片序列与自身内积为 1，与反码内积为 - 1，实现同一时间、同一频带无干扰通信。
    - 发送端处理：发送比特 1 时发送自身码片序列，发送比特 0 时发送码片序列的二进制反码。
    - 接收端处理：通过计算接收信号与目标用户码片序列的规格化内积，提取目标用户数据。

17. 介质访问控制主要有哪些？

    - 多路复用机制

      - FDM、TDM、CDM

    - 多路访问机制

      - 受控访问方法：轮询、令牌传递

      - 随机访问方法：ALOHA、时隙ALOHA、CSMA、CSMA/CA、CSMA/CD

18. 受控访问的两种常见方法及各自的缺点是什么？

    - 轮询法：主节点邀请从节点轮流传输数据，无冲突；缺点是存在轮询开销、传输延迟，且主节点单点故障会影响整个系统。
    - 令牌传递：令牌依次在节点间传递，持有令牌的节点可发送数据；缺点是存在令牌开销、传输延迟，令牌丢失会导致通信中断，且存在单点故障。

19. 纯 ALOHA 和时隙 ALOHA 的区别及各自特点是什么？

    - 区别：①发送时机：纯 ALOHA 可随时发送，时隙 ALOHA 需在时隙开始时发送；②同步要求：纯 ALOHA 无同步要求，时隙 ALOHA 需节点同步；③冲突检测：时隙 ALOHA 可在时隙结束前检测冲突，纯 ALOHA 冲突检测时机更晚。
    - 纯 ALOHA 特点：简单，适用于轻负载场景，冲突概率高，资源浪费严重。
    - 时隙 ALOHA 特点：简单，避免帧传输过程中冲突，资源浪费减少，但仍有冲突，存在空闲时隙，需持续同步。

20. CSMA 的三种类型及各自的工作原理是什么？

    - 非坚持 CSMA：听到信道忙则延迟随机时间后重新监听；可分为非时隙和时隙型；优点是减少再次冲突概率，缺点是浪费信道空闲时间。
    - 1 坚持 CSMA：听到信道忙则持续监听，信道空闲立即发送；优点是抓住发送时机，缺点是多节点同时监听易冲突。
    - p 坚持 CSMA：听到信道忙则持续监听，信道空闲以概率 p 发送，以概率（1-p）延迟后重新监听。

21. CSMA 无法完全避免冲突的原因是什么？

    - ①多个节点同时监听信道，发现信道空闲后同时发送数据，导致冲突；
    - ②存在传播延迟，节点发送数据后，其他节点需经过传播延迟才能检测到信道忙，在此期间其他节点可能发送数据，引发冲突。

22. CSMA/CD 的工作原理及冲突检测方法是什么？

    - 工作原理：①先监听，信道空闲则发送数据（1 坚持）；②边发送边监听，检测到冲突立即停止发送，并发送阻塞信号强化冲突；③发送阻塞信号后，采用二进制指数后退法退避随机时间（从 0,1,2,…,2ⁿ⁻¹ 中选 K，等待时间 = K×512bit 时间，n 为冲突次数），重新监听信道。
    - 冲突检测方法：①信号电平法（比较接收信号电压大小）；②过零点检测法（曼码中比较电压过零点位置）；③自发自收法（比较发送信号与接收信号）。
