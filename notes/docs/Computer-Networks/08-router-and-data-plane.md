# Router and Data Plane 路由器与数据平面

## 核心概念定义

1. 尽力而为（Best-effort）服务：网络层设计得尽量简单，向其上层只提供简单灵活的、无连接的、尽最大努力交付的数据报服务。

2. IP 地址：网络层地址，放在 IP 数据报的首部，用于局域网间寻址。

3. MAC 地址：数据链路层地址，放在 MAC 帧的首部，用于局域网内寻址。

4. ARP 地址解析协议：一种即插即用（plug-and-play）协议，用于根据已知的 IP 地址获取对应的 MAC 地址，节点生成 ARP 表无需网络管理员的干预。

5. ARP 高速缓存（ARP cache）：存放 IP 地址到 MAC 地址的映射表（ARP 表），映射表会动态更新（新增或超时删除）。

6. 路由器核心功能：

   - 路由选择（Routing）：决定分组从源端到目的端的传输路径，涉及路由算法与协议，是网络范围内的全局传输过程，属于控制平面的功能，通常由软件实现，耗时几秒。
   - 分组转发（Forwarding）：把分组从路由器的输入端口转发到合适的输出端口，依赖转发表，是每路由器的局部交换过程，属于数据平面的功能，通常由硬件实现，耗时几纳秒。

7. 直连路由：直接连接的网络所对应的路由，路由优先级通常为 0（不同厂家设备可能不同）。

8. 静态路由：由网络管理员手动配置的路由，路由优先级通常为 1（不同厂家设备可能不同）。

9. 等价路由：到一个目的地有多个相同开销的不同链路路径，IP 报文在这几个链路上轮流发送，以提高链路利用率。

10. 路由黑洞（无路由）：报文转发过程中，在某一节点的路由表中查不到对应目的地址的路由，导致报文被丢弃。

11. 黑洞路由（有路由）：指向 null 接口的路由，null 接口是一个无法配置 IP 地址的虚拟接口，转发到该接口的报文都被丢弃。

12. 最长前缀匹配规则：在转发表中寻找与分组首部目的 IP 地址最长的匹配项，并向与最长前缀匹配相关联的链路接口转发分组。

13. 线路前部阻塞（Head-of-the-Line (HOL) blocking）：队列前部排队的分组阻塞排在其后面分组的转发。

14. 交换结构（Switch Fabric）：实现分组从输入端口转发到合适的输出端口，主要有 Memory（内存式）、Bus（总线式）、Crossbar（纵横式）三种类型。

15. SDN（软件定义网络）：起源于 2006 年美国斯坦福大学 Clean State 课题组提出的一种新型网络创新架构，是网络虚拟化的一种实现方式，核心技术是通过 OpenFlow 协议将网络设备的控制层面与数据层面分离开来，实现网络流量的灵活控制。

16. ICMP（Internet Control Message Protocol）：允许主机或路由器报告差错情况和提供有关异常情况的报告，用于主机和路由器网络层信息的通信，ICMP 报文携带在 IP 数据报中（IP 首部协议号为 1）。

17. PING（Packet InterNet Groper）：用于测试两个主机之间的连通性，使用了 ICMP 回送请求与回送应答报文。

18. Traceroute/Tracert：跟踪一台主机到另一台主机的路由并测量延迟，通过发送一系列不同 TTL 值的 UDP 报文，利用 ICMP 报文反馈路由信息。

## 必考简答题预测

### 一、IP 地址与 MAC 地址相关

1. 问题：IP 地址与 MAC 地址的作用、位置及关系是什么？

   答案：

   - 作用：IP 地址是网络层地址，用于局域网间寻址；MAC 地址是数据链路层地址，用于局域网内寻址。
   - 位置：IP 地址放在 IP 数据报的首部；MAC 地址放在 MAC 帧的首部。
   - 关系：IP 数据报经过不同链路时，IP 地址不发生改变，而 MAC 帧中的 MAC 地址会发生改变；尽管互连在一起的网络的 MAC 地址体系各不相同，但 IP 层抽象的互联网屏蔽了下层复杂的细节，在网络层可使用统一的 IP 地址研究通信。
   
2. 问题：ARP 协议的功能和工作过程是什么？

   答案：

   - 功能：根据已知的 IP 地址获取对应的 MAC 地址，是即插即用协议，节点生成 ARP 表无需网络管理员干预。

   - 工作过程：

     1. 当主机 A 欲向本局域网上的主机 B 发送 IP 数据报时，先在其 ARP 表中查找主机 B 的 IP 地址对应的 MAC 地址。
  2. 若找到，取出对应的 MAC 地址写入 MAC 帧的目的地址，发送该 MAC 帧。
     3. 若未找到，自动运行 ARP，在本局域网内广播发送 ARP 请求报文（包含发送方硬件地址、发送方 IP 地址、目标方硬件地址（未知填全 0）、目标方 IP 地址），路由器不转发 ARP 请求。
        - 注意，MAC帧的目的地址为FF:FF:FF:FF:FF:FF（广播地址），ARP请求报文为00:00:00:00:00:00
     4. 主机 B 收到 ARP 请求报文后，向 A 单播发送 ARP 响应报文（包含发送方硬件地址、发送方 IP 地址、目标方硬件地址、目标方 IP 地址）。
     5. 主机 A 收到 ARP 响应报文后，更新 ARP 表。
     
3. 问题：跨局域网数据传输中，IP 层和 MAC 层的寻址过程是怎样的？（假设 A 知道 B 的 IP 地址、第一跳路由器 R 的 IP 地址和 MAC 地址）

   答案：

   1. A 生成 IP 报文，源 IP 为 A，目的 IP 为 B。
   2. A 生成以 R 的 MAC 地址为目的的链路层帧，包含 A 到 B 的 IP 报文，其中 MAC 源为 A 的 MAC 地址，MAC 目的为 R 的 MAC 地址。
   3. 帧从 A 发送到 R，R 收到帧后，提取出 IP 分组交给 IP 层。
   4. R 根据 A 为源 IP、B 为目的 IP 转发分组，生成以 B 的 MAC 地址为目的的帧，包含 A 到 B 的 IP 分组，其中 MAC 源为 R 的 MAC 地址，MAC 目的为 B 的 MAC 地址。
   5. 帧从 R 发送到 B，B 收到帧后，提取出 IP 分组交给 IP 层。
   
   

### 二、路由器相关

1. 问题：路由器的两大核心功能是什么？分别属于哪个平面？有何区别？

   答案：

   - 核心功能：路由选择和分组转发。

   - 所属平面：路由选择属于控制平面；分组转发属于数据平面。

   - 区别：

     - 路由选择：是网络范围内的全局传输过程，涉及路由算法与协议，由软件实现，耗时通常几秒。
     - 分组转发：是每路由器的局部交换过程，依赖转发表，由硬件实现，耗时通常几纳秒。

2. 问题：路由器控制平面的工作原理是什么？

   答案：

   - 路由器可同时运行多个路由协议，也可不运行任何路由协议，只使用静态路由和直连路由。
   - 路由选择根据路由优先级（数值越小优先级越高）选择最佳路由，形成核心路由表。
   - 控制平面将核心路由表下发到数据平面，形成转发表（FIB）。

3. 问题：什么是等价路由、路由黑洞、黑洞路由？

   答案：

   - 等价路由：到一个目的地有多个相同开销的不同链路路径，IP 报文在这几个链路上轮流发送，以提高链路利用率，一般路由协议都支持。
   - 路由黑洞（无路由）：报文转发的过程中，在某一节点的路由表中查不到对应目的地址的路由，则丢弃报文。
   - 黑洞路由（有路由）：指向 null 接口的路由，null 接口是一个无法配置 IP 地址的虚拟接口，转发到该接口的报文都被丢弃。

4. 问题：路由器数据平面中输入端口的功能是什么？

   答案：

   - 链路层解封装，进行 IP 头部校验。
   - 根据分组首部目的 IP 地址，使用驻留在输入端口内存中的转发表基于最长前缀匹配规则查找输出端口（“匹配 + 动作”）。
   - 若分组到达速率快于交换结构的转发速率，需要在输入端口排队，可能产生排队时延或因输入缓存溢出导致丢包，还可能出现线路前部阻塞（HOL blocking）。

5. 问题：路由器交换结构有哪几种类型？各自特点是什么？

   答案：

   - 内存式：第一代路由器采用，基于内存进行交换。
   - 总线式：广播式传输，存在总线竞争，适用于小型网络。
   - 纵横式：可并行转发多个分组，性能较好。

6. 问题：路由器输出端口的队列调度机制有哪几种？各自特点是什么？

   答案：

   - FIFO（First In First Out）调度：按照分组到达顺序发送，丢包策略包括丢弃尾部分组、基于优先级丢弃、随机丢弃。
   - 优先级调度：根据分组的优先级选择转发分组，分为多个类（队列），每个类（队列）具有不同优先级，分类可依赖标记或其他分组首部信息（如 IP 源 / 目的地址、源 / 目的端口号等）。
   - 轮询（Round Robin）调度：多个类（队列）以循环的方式轮流从每个类（队列）中发送一个分组（如果可用）。
   - 加权公平排队（Weighted Fair Queuing）：对轮询调度策略的改进，每一类（队列）在每一个周期中得到服务的权重不同。

7. 问题：SDN 的产生动机、主要思想、四个关键特征和体系结构是什么？

   答案：

   - 产生动机：传统控制平面与数据平面集中实现的路由器存在诸多问题，如庞大而单一、不同网络功能对应不同中间盒子、对流量工程支持不够等，借鉴从大型主机到 PC 机演变的启示，提出 SDN 架构。

   - 主要思想：通过 OpenFlow 协议将网络设备的控制层面与数据层面分离开来，实现网络流量的灵活控制，为核心网络及应用的创新提供平台（SDN 不是具体技术，而是一种思想理念，不等于 OpenFlow，OpenFlow 是 SDN 南向接口的一种具体实现形式）。

   - 四个关键特征：控制平面与数据平面分离；基于流的转发；网络控制功能（路由控制、访问控制、负载均衡等）位于交换机外部，软件实现；可编程的网络。

   - 体系结构：

     - 数据平面：SDN 交换机（快速、简单，基于硬件实现数据转发），包含流表（由控制器计算和部署）。
     - 控制平面：SDN 控制器（维护网络状态信息，计算、部署流表）；网络控制应用（通过 SDN 控制器提供的 API 实现控制功能，可由第三方提供）。
     - 接口：北向 API（连接网络控制应用与 SDN 控制器）；南向 API（如 OpenFlow，连接 SDN 控制器与数据平面）。




### 三、ICMP 协议相关

1. 问题：ICMP 协议的功能、报文类型是什么？

   答案：

   - 功能：允许主机或路由器报告差错情况和提供有关异常情况的报告，用于主机和路由器网络层信息的通信，ICMP 报文携带在 IP 数据报中（IP 首部协议号为 1）。
- 报文类型：
  
  - 差错报告报文：类型值 3（终点不可达）、5（改变路由（Redirect））、11（时间超时）、12（参数问题）。
     - 询问报文：类型值 8 或 0（回送（Echo）请求或应答）、13 或 14（时间戳（Timestamp）请求或回答）。（注：根据 RFC6633 规定，已不再使用类型值为 4、10 或 9、15 或 16、17 或 18 的报文）

2. 问题：PING 的功能和工作原理是什么？

   答案：

   - 功能：测试两个主机之间的连通性，还能获取往返时延、单向转发跳数等信息。
   - 工作原理：PING 使用 ICMP 回送请求与回送应答报文，源主机向目的主机发送 ICMP 回送请求报文，目的主机收到后返回 ICMP 回送应答报文，源主机通过接收应答报文判断与目的主机的连通性，并计算往返时延等参数。
   
3. 问题：Traceroute/Tracert 的功能和工作原理是什么？

   答案：

   - 功能：跟踪一台主机到另一台主机的路由并测量延迟。
   - 工作原理：
     1. 源端发送一系列 UDP 报文，且 UDP 端口号不可达，第一组报文 TTL=1，第二组报文 TTL=2，依次类推。
     2. 当第 n 组报文到达第 n 个路由器时，路由器丢弃该报文，并向源端发送一个 ICMP 报文（type 11，code 0），ICMP 报文中包含该路由器的名字和 IP 地址；当 ICMP 报文返回源端时，源端记录 RTT。
     3. UDP 报文最终到达目的端主机，目的端主机返回 ICMP “端口不可达” 的消息（type 3，code 3），源端停止发送。
