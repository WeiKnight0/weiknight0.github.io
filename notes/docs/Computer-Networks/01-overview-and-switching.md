# 计算机网络

计算机网络利用通信设备和线路，将地理位置不同、功能独立的多台主机互连起来，在协议控制下实现信息传递和资源共享。

计算机网络包含三个核心要素：

- **主机**：地理位置不同的自主计算机，是网络中处理信息的主体；
- **通信设备和线路**：连接主机并传输信息，包括路由器、交换机、光纤和双绞线等；
- **协议**：主机之间交换信息时共同遵守的规则和标准。

计算机网络由资源子网和通信子网组成：

- **资源子网**完成信息处理，包含主机、服务器等设备，提供硬件、软件和数据资源；
- **通信子网**完成信息传输，包含路由器、交换机、通信链路等传输设备和数据交换设备。

计算机网络用于通信和资源共享，也可通过多条传输路径降低单点故障对系统可靠性的影响。

# 计算机网络的分类

按分布范围可以分为：

- **个域网（PAN）**：面向个人的小型网络，如个人设备之间的蓝牙网络；
- **局域网（LAN）**：覆盖校园、企业、办公楼等较小地理范围，传输速率较高、误码率较低；
- **城域网（MAN）**：覆盖一个城市，用于连接城市内的多个局域网；
- **广域网（WAN）**：覆盖国家、全球等广阔区域，传输距离远，常借助公共通信网络互联。

按管理性质可以分为公用网和专用网。CERNET、ChinaNet 属于公用网；金融网、军网等由特定组织使用，属于专用网。

按传输介质可以分为有线网和无线网。有线网使用双绞线、同轴电缆、光纤等介质；无线网使用无线电波、微波、红外线等介质。

# 互联网与因特网

**互联网（internet）**泛指由多个不同类型的计算机网络互联而成的网络，是通用名词，除 TCP/IP 外也可以使用其他协议。

**因特网（Internet）**特指遵循 TCP/IP 标准、利用路由器连接不同计算机网络并覆盖全球的互联网，是专用名词。当前“互联网”也被用作 Internet 的事实译名。

二者都是“网络的网络”，区别在于互联网是一类网络，因特网是其中一个具体实例。

# 网络边缘、接入网与网络核心

互联网由网络边缘、接入网和网络核心组成。

- **网络边缘**包含客户端和服务器等端系统。端系统属于资源子网，是数据的产生者和消费者；
- **接入网**将端系统连接到边缘路由器；
- **网络核心**包含相互连接的路由器，属于通信子网，负责将数据传到目标主机。

接入网主要分为：

- **家庭接入**：DSL、电缆接入、FTTH；
- **企业接入**：以太网、WiFi；
- **移动接入**：WiFi、4G、5G 等。

DSL 使用电话线连接数字用户线接入复用器（DSLAM），语音使用低频段，数据使用高频段，上下行速率通常不对称。

FTTH 将光纤铺设到用户住宅，分为有源光纤网络（AON）和无源光纤网络（PON）。PON 中，光网络终端（ONT）经过一个或多个无源分光器连接到局端的光线路终端（OLT）。

互联网的 ISP 呈层级结构：

1. 顶层是 Tier 1 ISP，即骨干 ISP，彼此之间通常通过对等连接互联；
2. 中间是 Regional ISP，连接骨干 ISP 和接入 ISP；
3. 底层是 Access ISP，直接为家庭和企业提供网络接入；
4. 内容提供商网络还可通过因特网交换点（IXP）或对等链路与各级 ISP 互联。

# 电路交换

电路交换是面向连接的数据传输方式。通信前需要建立端到端电路，并为通信双方预留链路带宽和交换能力。

电路交换依次经过三个阶段：

1. 建立电路；
2. 传输数据；
3. 释放电路。

电路交换的资源由通信双方独占，实时性较好；但线路利用率低，任一节点发生故障后需要重新建立连接，也不便于不同类型、不同速率的终端通信。

# 分组交换

分组交换将应用层数据划分为若干分组。路由器完整接收一个分组后，再将它发送到下一跳，这一过程称为**存储转发**。

每个分组的首部包含源地址、目的地址等控制信息。来自不同主机的分组按需共享链路和设备，即统计多路复用。分组交换适合突发流量，网络资源利用率高；代价是增加分组首部开销，并可能因拥塞产生排队时延、丢包，而且不保证带宽。

电路交换与分组交换的区别如下：

| 比较项 | 电路交换 | 分组交换 |
| --- | --- | --- |
| 资源分配 | 静态分配，预留资源 | 动态分配，按需共享 |
| 传输方式 | 透明传输 | 半透明传输 |
| 传统计费依据 | 通信时间 | 传输字节数 |

# 虚电路与数据报

虚电路和数据报是分组交换的两种实现方式。

| 比较项 | 虚电路 | 数据报 |
| --- | --- | --- |
| 连接 | 通信前建立逻辑连接 | 无需建立连接 |
| 分组地址 | 建立连接时使用完整地址，传输时使用虚电路号 | 每个分组携带完整目的地址 |
| 路由 | 同一虚电路的分组沿同一路由转发 | 每个分组独立选择路由 |
| 到达顺序 | 分组按序到达 | 分组可能乱序 |
| 故障影响 | 故障路由器上的虚电路均失效 | 部分分组可能丢失，后续分组可改变路由 |
| 可靠性 | 通常由网络保证 | 通常由主机保证 |

# 路由与转发

**路由**是网络核心的全局操作，负责确定分组从源主机到目的主机经过的路径，需要使用路由协议和路由算法。

**转发**是路由器内部的本地操作，负责根据本地转发表将收到的分组送到对应输出链路。

# 多路复用

多路复用将若干彼此无关的信号合并为一个复合信号，在一条共享信道上传输：

- **频分多路复用（FDM）**：把信道带宽划分为互不重叠的子信道，不同信号同时占用不同频段；
- **时分多路复用（TDM）**：把时间划分为固定时隙，不同信号轮流使用信道；
- **波分多路复用（WDM）**：把不同波长的光信号复用到同一根光纤，本质上属于频分多路复用。
