# Computer Network Overview 网络导论与交换

## 【核心概念定义】

1. 计算机网络：利用通信设备和线路将地理位置不同、功能独立的多台主机互连起来，在协议控制下实现信息传递和资源共享的系统。
2. 资源子网：完成信息的处理（计算机技术），包含主机、服务器等。
3. 通信子网：完成信息的传输（计算机技术 + 通信技术），包含路由器、交换机、通信链路等传输设备及数据交换设备。
4. 个域网（PAN）：按分布范围划分的计算机网络类型，是面向个人的小型网络。
5. 局域网（LAN）：按分布范围划分的计算机网络类型，局限于较小地理范围（如校园、企业内部）的网络。
6. 城域网（MAN）：按分布范围划分的计算机网络类型，覆盖城市范围的网络。
7. 广域网（WAN）：按分布范围划分的计算机网络类型，覆盖广阔地理区域（如国家、全球）的网络。
8. 公用网：按管理性质划分的计算机网络类型，如 CERNET（中国教育科研网）、ChinaNet（中国宽带互联网）。
9. 专用网：按管理性质划分的计算机网络类型，如金融网、军网等，为特定组织专用。
10. 有线网：按传输介质划分的计算机网络类型，采用双绞线、同轴电缆、光纤等传输介质。
11. 无线网：按传输介质划分的计算机网络类型，采用无线电波、微波、红外线等传输介质。
12. 互联网（internet）：泛指由多个不同类型计算机网络互联而成的网络，是 “网络的网络”，除 TCP/IP 外还可使用其他协议，是通用名词。
13. 因特网（Internet）：特指遵循 TCP/IP 标准、利用路由器将各种计算机网络互联起来覆盖全球的特定互联网，是 “网络的网络” 的具体实例，是专用名词，当前已被 “互联网” 作为事实译名。
14. 端系统（主机）：网络边缘的设备，包括客户端和服务器，属于资源子网。
15. 接入网：将主机连接到边缘路由器的网络，包括家庭接入、企业接入、移动接入等类型。
16. 电路交换：面向连接的数据传输方式，数据传输前需建立端到端通路（电路），预留资源，分为建立电路、传输数据、释放电路三个阶段，资源独占。
17. 分组交换：无连接的数据传输方式，主机将应用层数据分成若干分组，路由器接收完整分组后存储转发，分组首部含地址等控制信息，独立选择传输路径，按需共享链路和设备。
18. 虚电路（VC）：分组交换的实现方式之一，面向连接，通信前建立逻辑连接，分组沿该逻辑连接存储转发，并非物理连接。
19. 数据报：分组交换的实现方式之一，无连接、尽力而为的通信方式，发送分组无需先建立连接，每个分组独立发送、独立选择路由。
20. 路由：网络核心的全局操作，路由器确定分组从源到目的经过的路径，需使用路由协议和路由算法。
21. 转发：网络核心的本地操作，路由器根据本地转发表将接收到的分组转发到相应的输出链路。
22. 多路复用：将若干彼此无关的信号合并为一个复合信号，在一条共用信道上传输，提高线路利用率，包括频分多路复用（FDM）、时分多路复用（TDM）、波分多路复用（WDM）等。

## 【必考简答题预测】

1. 计算机网络的定义包含哪三个核心要素？请分别解释。
   - 标准答案：计算机网络定义的三个核心要素如下：
     - 主机：指地理位置不同的自主计算机，是网络中信息处理的主体。
     - 通信设备和线路：用于保证主机之间能够互相连接，是网络信息传输的基础设施，如路由器、交换机、光纤、双绞线等。
     - 协议：用于保证主机之间能够互相交换信息，是网络中信息传输的规则和标准。
2. 计算机网络的组成是什么？资源子网和通信子网分别承担什么功能？
   - 标准答案：计算机网络由资源子网和通信子网组成。
     - 资源子网：完成信息的处理（基于计算机技术），包含主机、服务器等设备，提供硬件资源、软件资源、数据资源的共享。
     - 通信子网：完成信息的传输（基于计算机技术 + 通信技术），包含路由器、交换机、通信链路等传输设备及数据交换设备，负责将资源子网处理后的信息准确传输到目标节点。
3. 计算机网络有哪些主要功能？
   - 标准答案：计算机网络的主要功能包括：
     - 提供强大的通信手段，实现不同地理位置主机之间的信息传递。
     - 提供资源共享，包括硬件资源、软件资源、数据资源的共享。
     - 提高系统的可靠性，通过多路径传输等方式降低单点故障对系统的影响。
4. 计算机网络按分布范围可分为哪几类？请分别简要说明。
   - 标准答案：按分布范围划分，计算机网络可分为：
     - 个域网（PAN）：面向个人的小型网络，覆盖范围最小，如个人设备之间的蓝牙连接网络。
     - 局域网（LAN）：局限于较小地理范围（如校园、企业内部、办公楼）的网络，传输速率较高，误码率低。
     - 城域网（MAN）：覆盖城市范围的网络，用于连接城市内的多个局域网。
     - 广域网（WAN）：覆盖广阔地理区域（如国家、全球）的网络，传输距离远，常借助公共通信网络实现互联。
5. 互联网（internet）和因特网（Internet）的异同点是什么？
   - 标准答案：互联网（internet）和因特网（Internet）的异同点如下：
     - 相似之处：二者都是 “网络的网络”，互联网是泛指这种类型，因特网是该类型的一个具体实例。
     - 不同之处：
       - 范围与特指性：互联网泛指由多个不同类型计算机网络互联而成的网络；因特网特指遵循 TCP/IP 标准、利用路由器将各种计算机网络互联起来覆盖全球的特定互联网。
       - 协议使用：互联网除 TCP/IP 外，还可使用其他协议；因特网仅使用 TCP/IP 协议。
       - 名词属性：互联网是通用名词；因特网是专用名词，是全球最大的互联网，是计算机网络的一个实例。
6. 互联网的网络边缘和网络核心分别包含什么？各自的作用是什么？
   - 标准答案：
     - 网络边缘：包含主机（端系统），即客户端和服务器，属于资源子网。作用是作为网络应用的载体，提供信息处理和资源共享的基础，是数据的产生者和消费者。
     - 网络核心：包含互相连接的路由器，是 “网络的网络”，属于通信子网。作用是通过路由和转发功能，将网络边缘产生的数据准确、高效地传输到目标主机。
7. 互联网的接入网有哪些主要类型？请分别列举对应的接入技术。
   - 标准答案：互联网的接入网主要分为家庭接入、企业接入、移动接入三类，对应的接入技术如下：
     - 家庭接入：数字用户线（DSL）、电缆接入（Cable Access）、光纤到户（FTTH，分为有源光纤网络 AON 和无源光纤网络 PON）。
     - 企业接入：以太网、WiFi 接入。
     - 移动接入：WiFi（无线局域网）、4G/5G（广域蜂窝接入网络）等。
8. 电路交换的定义、三个阶段及特点是什么？
   - 标准答案：
     - 定义：电路交换是面向连接的数据传输方式，数据传输前需要建立一条端到端的通路（电路），预留链路带宽资源、交换机的交换能力。
     - 三个阶段：建立电路、传输数据、释放电路。
     - 特点：资源独占，传输性能好（实时性好）；但线路利用率低，若发生故障，传输会被中断；对不同类型、不同速率的终端很难进行通信；不够灵活，任一点出现故障必须重新建立连接。
9. 分组交换的定义、核心机制及特点是什么？
   - 标准答案：
     - 定义：分组交换是无连接的数据传输方式，主机将应用层数据分成若干个分组，路由器需要接收到完整的整个数据分组后，才能开始向下一跳发送，分组逐跳传输抵达目的地。
     - 核心机制：存储转发机制，每个分组的首部都含有地址（目的地址和源地址）等控制信息，在互联网中独立地选择传输路径；不同主机的分组按需共享链路和设备，即统计多路复用。
     - 特点：优点是提高网络资源利用率，简单、有效、成本低，适合突发流量；缺点是增加开销，容易产生拥塞，增加分组时延和丢包率（不保证带宽）。
10. 电路交换和分组交换在通信资源分配方式、信息传输透明度、资费政策上有何区别？
    - 标准答案：
      - 通信资源分配方式：电路交换是静态分配（预留资源）；分组交换是动态分配（按需分配资源）。
      - 信息传输透明度：电路交换是透明传输；分组交换是半透明传输。
      - 资费政策：电路交换按照时间计费；分组交换按照字节数计费。
11. 分组交换的实现方式有哪两种？请分别说明它们的核心特点。
    - 标准答案：分组交换的实现方式包括虚电路和数据报，核心特点如下：
      - 虚电路：
        - 可靠通信由网络保证。
        - 通信前必须建立虚电路（逻辑连接）。
        - 终点地址仅在连接建立阶段使用，每个分组使用短的虚电路号。
        - 属于同一条虚电路的分组均按照同一路由进行转发。
        - 所有通过故障路由器的虚电路均不能工作。
        - 分组总是按序到达终点。
        - 网络或主机负责差错处理、流量控制，拥塞控制容易。
      - 数据报：
        - 可靠通信由主机保证。
        - 不需要建立连接。
        - 每个分组都有终点的完整地址。
        - 每个分组独立选择路由进行转发。
        - 故障路由器可能会丢失分组，一些路由可能会发生变化。
        - 分组到达终点时可能乱序。
        - 主机负责差错处理、流量控制，拥塞控制困难。
12. 互联网网络核心的两大功能是什么？请分别解释。
    - 标准答案：互联网网络核心的两大功能是路由和转发。
      - 路由：属于全局操作，路由器确定分组从源到目的经过的路径，需要使用路由协议和路由算法。
      - 转发：属于本地操作，路由器根据本地转发表将接收到的分组转发到相应的输出链路。
13. 多路复用技术有哪些类型？请简要说明其原理。
    - 标准答案：常见的多路复用技术包括频分多路复用（FDM）、时分多路复用（TDM）、波分多路复用（WDM）。
      - 频分多路复用（FDM）：将信道的带宽划分为若干个互不重叠的子信道，每个子信道分配给一个信号使用，不同信号在不同子信道上同时传输，基于频率划分。
      - 时分多路复用（TDM）：将时间划分为若干个固定长度的时隙，每个时隙分配给一个信号使用，不同信号在不同时隙上轮流传输，基于时间划分。
      - 波分多路复用（WDM）：本质上是频分多路复用的一种，适用于光纤通信，将不同波长的光信号复用到一根光纤上传输，每个波长对应一个子信道。
14. 家庭接入中的 DSL 和 FTTH 技术有何特点？
    - 标准答案：
      - DSL（数字用户线）：使用电话线连接到数字用户线接入复用器（DSLAM），语音（低频）和数据（高频）通过专线（电话线）的不同频段传输到中心局；上下速率不对称，下行速率 24-52 Mbps，上行速率 3.5-16 Mbps；我国早期使用，国外依然大量使用。
      - FTTH（光纤到户）：我国及全球先进地区普遍采用的光纤通信传输方法，分为有源光纤网络 AON 和无源光纤网络 PON；带宽大（千兆比特 / 秒）、线路稳定；无源光纤网络 PON 中，光猫 ONT 通过一个或多个无源分光器，连接到局端的光线路终端 OLT。
15. 互联网的层级结构是怎样的？主要包含哪些层级的 ISP？
    - 标准答案：互联网呈现层级结构，主要包含以下层级：
      - 顶层：Tier 1 ISP（骨干 ISP），目前有十几个，互不结算，如 Level3 Communication、AT&T、Sprint、NTT、中国三大运营商等。
      - 中层：Regional ISP（区域 ISP），连接 Tier 1 ISP 和底层 ISP。
      - 底层：access ISP（接入 ISP），直接为家庭、企业等用户提供互联网接入服务。
      - 此外，还包含内容提供商网络（如 Google），通过因特网交换点（IXP）、对等链接等与各级 ISP 互联。
