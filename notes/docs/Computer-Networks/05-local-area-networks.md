# 局域网

局域网（LAN）将有限地理范围内的独立设备互联起来，实现设备间通信和资源共享。

**冲突域**是一个站点发出的帧可能与其他站点所发帧产生冲突的网络范围；**广播域**是一台设备发出的广播帧能够到达的网络范围。

# IEEE 802 参考模型

## IEEE 802 的层次

IEEE 802 参考模型分为逻辑链路控制（LLC）子层、媒体接入控制（MAC）子层和物理层。

- 媒体接入控制（MAC）子层：处理与传输介质接入相关的问题；向上层提供介质访问控制方式；实现帧的寻址和识别；产生帧检验序列，完成帧检验。
- 逻辑链路控制（LLC）子层：处理与传输介质接入无关的问题；建立和释放数据链路层的连接；向高层提供服务接口；给帧加序号。
- 物理层：负责处理物理介质上的信号传输，为 MAC 子层提供物理连接。

## 局域网的差异层次

物理层和 MAC 子层。

# 以太网

## 以太网 MAC 帧格式

两种标准分别是 DIX Ethernet V2 标准（最常用）和 IEEE 的 802.3 标准。

主要区别：帧结构中对应的字段不同，DIX Ethernet V2 标准中是 “类型” 字段（2 字节），IEEE 802.3 标准中是 “长度” 字段（2 字节）；判断方式为 Length/Type≥1536（0×0600）为 Ethernet V2 帧，Length/Type≤1500（0×05DC）为 IEEE 802.3 帧。

## 最短有效帧长

802.3 规范中的 10Mbps 以太网，最大长度为 2500 米，具有 4 个中继器，在最差情况下往返一次时间大约是 50 微秒，在这个时间内能发送 500bit，加上安全余量增加至 512bit，即 64Bytes。凡长度小于 64 字节的帧都是由于冲突而异常中止的无效帧，因为一检测到冲突就立即中止发送，这时已经发送出去的数据一定小于 64 字节。

## 共享式与交换式以太网

- 冲突域：共享式以太网中所有端口处于同一个冲突域；交换式以太网中每个端口都有独立的冲突域，全双工模式下无需 CSMA/CD 机制。
- 带宽分配：共享式以太网中 N 个用户共享集线器提供的带宽 B，平均每个用户仅占有 B/N 的带宽；交换式以太网为每个端口提供带宽 B，N 个用户的网络总容量为 B×N/2，每个用户独享带宽。
- 设备工作层次：集线器工作在物理层；交换机工作在数据链路层，实质上是多接口网桥。
- 转发机制：集线器对收到的信号进行放大转发，所有端口都能接收；交换机对收到的帧查找转发表，根据目的 MAC 地址进行转发或过滤，具有并行性，能同时连通多对接口。

## 交换机的自学习与转发

- 开始：交换机收到帧后，先从帧中取出源地址和目的地址。
- 源地址处理：若转发表中无该源地址，将该地址、对应的进入接口和有效时间加入转发表；若已有该地址且接口与帧进入的接口不同，更新转发表中的该地址项（接口和有效时间）；若接口相同则不做处理。
- 目的地址处理：若转发表中有该目的地址，向指定接口转发；若没有，向所有其他接口转发（进入的接口除外，即泛洪）；若目的地址对应的接口与帧进入的接口相同，则丢弃该帧（过滤）。
- 有效时间：转发表中每个表项都设有一定的有效时间（默认 300s），过期的表项自动被删除。


# 虚拟局域网 VLAN

虚拟局域网（VLAN）将局域网网段按照共同需求组成与物理位置无关的逻辑组。每个 VLAN 帧带有标识符，用于说明发送该帧的计算机属于哪个 VLAN。

## VLAN 的作用

- 有效控制广播域范围：广播流量被限制在一个 VLAN 内；

- 增强网络的安全性：VLAN 间相互隔离，无法进行二层通信，不同 VLAN 需通过三层设备通信；
- 灵活构建虚拟工作组：同一工作组的用户不必局限于同一物理范围；
- 提高网络的可管理性：将不同的业务规划到不同 VLAN 便于管理。

## VLAN 的划分方式

- 基于端口的 VLAN（最常见）：划分依据是交换机的端口，创建 VLAN 后指定成员端口，每个 Access 端口只能加入一个 VLAN；

- 基于 MAC 地址的 VLAN：划分依据是设备的 MAC 地址，MAC 地址决定了设备的 VLAN 成员身份；
- 基于协议的 VLAN：划分依据是设备运行的网络协议，如 IP 协议、IPX 协议等；
- 基于子网的 VLAN：划分依据是 IP 子网，一个子网就是一个 VLAN。

## Access 与 Trunk 端口

区别：

- Access 端口：一般用于连接用户设备（无需识别 802.1Q 帧的设备）；每个 Access 端口只能加入一个 VLAN；发送帧时剥离 VLAN 标记，接收帧时添加对应 VLAN 标记；

- Trunk 端口：一般用于交换机之间连接；允许多个 VLAN 的流量通过；发送帧时携带 VLAN 标记（除 PVID 对应的 VLAN 外），接收帧时识别 VLAN 标记并转发到对应 VLAN。

  应用场景：

- Access 端口：连接 PC、打印机等终端设备；

- Trunk 端口：交换机之间的互联链路（汇聚链路），实现不同交换机上相同 VLAN 的设备互通。

## 802.1Q 帧

- 帧结构：标准以太网帧的结构为 “目的地址（6 字节）+ 源地址（6 字节）+ 长度 / 类型（2 字节）+ 数据（42~1500 字节）+FCS（4 字节）”；802.1Q 帧在源地址和长度 / 类型字段之间插入了 4 字节的 VLAN 标记（TCI，标记控制信息）；

- 帧长：以太网 MAC 帧的最大帧长从原来的 1518 字节变为 1522 字节；
- VLAN 标记字段：包含 3 位用户优先级（PRI）、1 位规范格式指示符（CFI）、12 位 VLAN 标识符（最多允许 4096 个 VLAN），标记类型为 0X8100。

## VLAN 间通信

不同 VLAN 成员之间不能直接进行二层通信，需要通过路由器或三层交换机进行 VLAN 间路由，实现不同 VLAN 之间的数据包转发。

# 无线局域网 WLAN

无线局域网（WLAN）使用无线信道作为传输介质。

- **基本服务集（BSS）**：由一个 AP 和多个站点（STA）组成；
- **扩展服务集（ESS）**：多个 BSS 通过分布式系统（DS）互联；
- **独立基本服务集（IBSS）**：没有固定基础设施，站点之间直接通信并共享同一无线信道。

## WLAN 组网模式

- 基础架构模式（有固定基础设施）：包含站点（STA）、访问点（AP）、分布式系统（DS）、基本服务集（BSS）、扩展服务集（ESS）；站点之间通信通过 AP 转发；可实现较大范围的无线覆盖和站点漫游。

- 自组织模式（Ad hoc，无固定基础设施）：由站点（STA）组成独立基本服务集（IBSS）；站点之间直接通信，共享同一无线信道；无需 AP 支持，部署灵活，但覆盖范围小、性能有限。

## 关联与扫描

移动站点加入 BSS 时，需要与 AP 建立关联。移动站将关联转移到另一个 AP 称为重建关联，终止与 AP 的关联称为分离。

建立关联的方法有被动扫描和主动扫描两种。

- 被动扫描流程：AP 周期性发出信标帧（beacon frame），其中包含 SSID、速率等系统参数；移动站点从接收到信号的 AP 中选择目标 AP，向该 AP 发出关联请求帧（Association Request frame）；目标 AP 同意请求，向移动站点发送关联响应帧（Association Response frame），关联建立。
- 主动扫描流程：移动站点主动发出广播的探测请求帧（Probe Request frame）；所有能收到该帧的 AP 都回答探测响应帧（Probe Response frame）；移动站点从响应的 AP 中选择目标 AP，向其发出关联请求帧；目标 AP 向移动站点发送关联响应帧，关联建立。

## CSMA/CA 的原因

不能使用 CSMA/CD 的原因：

- 冲突检测困难：无线信道中信号衰减随时间变化，且存在终端隐藏问题和终端暴露问题；

- 终端隐藏问题：由于距离太远或障碍物导致站点无法检测到竞争对手的存在。在同一 BSS 中，不是所有站点都能互相感知到对方发送的信号，隐藏站点不能侦听到发送端但能干扰接收端；

- 终端暴露问题：由于侦听到其他站点的发送而误以为信道忙导致不能发送。暴露站点能侦听到发送端但不会干扰接收端，若直接禁止发送会降低网络吞吐量。

  采用 CSMA/CA 的原因：CSMA/CA 通过冲突避免机制尽量减少冲突发生的概率，同时使用停止等待协议（链路层确认）解决冲突后重传问题，适应无线信道的特性。

## CSMA/CA

- 当信道空闲时间大于 IFS（帧间间隔），立即传输；
- 当信道忙时，延迟直到当前传输结束 + IFS 时间；
- 等待结束后，如果信道忙，则继续等待；如果信道空闲，则开始随机退后过程（二进制指数退后）；
   - 退后过程中如果信道忙，则挂起退后过程；
   - 在当前帧传输结束后恢复退后过程；
   - 使用退后过程延迟发送的目的是避免多个站点同时传输引起的冲突。

## 帧间间隔 IFS

IFS（帧间间隔）的取值根据帧的类型和优先级决定，具体分为以下四种：

1. 短帧间间隔（SIFS）：最短，用于需要立即响应的帧（如 ACK 和 CTS 帧），这类帧具有高优先级，等待时间较短；

2. 点协调功能帧间间隔（PIFS）：中等长度，主要用于 PCF（点协调功能，集中控制接入方式）操作中的轮询过程；

3. 分布协调功能帧间间隔（DIFS）：较长，用于一般的数据帧传输；

4. 扩展帧间间隔（EIFS）：比 DIFS 更长，用于在前一帧出错的情况下，发送节点延迟一段时间后再发送下一帧。

同一设备不同时刻可能因发送不同类型的帧而使用不同的 IFS 值。

## RTS/CTS

作用：通过信道预约，避免长帧冲突；RTS 和 CTS 帧很短，即使产生冲突，信道浪费较少。

流程：
- 发送端发送 RTS（request to send）帧，申请信道使用权；
- 接收端收到 RTS 帧后，回送 CTS（clear to send）帧，告知发送端信道可用；
- 其他相关站点能够收到 RTS 或（和）CTS 帧后，延迟传输数据，避免与当前通信冲突。

## DCF 与 PCF

MAC 层包含分布协调功能（DCF）和点协调功能（PCF）。

- 分布协调功能（DCF）：必须实现；基于 CSMA/CA 机制；分布式控制方式，各站点自主竞争信道使用权。
- 点协调功能（PCF）：选用；集中控制方式；通过 AP 进行轮询，为站点分配信道使用权；使用 PIFS 帧间间隔，优先级高于 DCF。

## 802.11 MAC 帧

MAC 帧的类型：控制帧、管理帧、数据帧。

数据帧四个地址字段的作用：

- 地址 1：永远是接收地址（即直接接收数据帧的节点地址）；
- 地址 2：永远是发送地址（即实际发送数据帧的节点地址）；
- 地址 3 和地址 4：取决于数据帧中的 “来自 AP” 和 “去往 AP” 这两个字段的数值；地址都是 MAC 地址（硬件地址），AP 的 MAC 地址是 BSSID。
