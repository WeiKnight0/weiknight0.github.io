# Network Architecture and Performance 网络体系结构与性能

## 【核心概念定义】

1. **层（Layer）**：开放系统的逻辑划分，包含当前层（N 层）、上一层（N+1 层）、下一层（N-1 层）。
2. **层功能**：本层具有的功能（对内）。
3. **层服务**：本层向上一层提供的功能（对外），N 层服务 = N 层功能 +（N-1）层服务。
4. **接口**：位于相邻层之间，定义了下层向上层提供的服务原语。
5. **协议**：位于对等层之间，为进行网络中的数据交换而建立的规则、标准或约定，通信双方需要共同遵守、互相理解，是保证能够向上一层提供服务的基础。
6. **协议三要素**：语法（数据与控制信息的结构或者格式）、语义（协调双方动作的信息及其含义）、时序（规定动作的时间、事件的实现顺序等）。
7. **网络体系结构（Architecture）**：计算机网络的各层及其协议的集合。
8. **OSI 参考模型**：Open System Interconnection，由 Day 和 Zimmermann 于 1983 年提出，被 ISO 定为国际标准，是具有 7 层结构的开放系统互联参考模型。
9. **TCP/IP 参考模型**：由 ARPANET 所采用，以 TCP 和 IP 协议命名，Vint Cerf 和 Bobert Kahn 于 1974 年提出，是具有 4 层结构的参考模型。
10. **速率（Rate）**：单位时间内主机在数字信道上传送的数据量，也称比特率，单位是 b/s（比特每秒），也可写为 bps，或 Kb/s、Mb/s、Gb/s 等。
11. **带宽（Bandwidth）**：模拟信道中指允许传输信号的频率范围（频带宽度），单位 Hz；数字信道中指单位时间内所能通过的 “最大数据量”，单位 bit/s。
12. **吞吐量（Throughput）**：单位时间内发送者和接收者之间传输的数据量，单位 bps，包括瞬时吞吐量、平均吞吐量、有效吞吐量（单位时间内目的端正确接收到的有用数据量）。
13. **瓶颈链路**：端到端路径上制约吞吐量的链路。
14. **时延（Delay）**：包括节点时延，节点时延 = 处理时延 + 排队时延 + 传输时延 + 传播时延。
15. **处理时延（d_proc）**：检查比特错误、决定输出链路所花费的时间，为微秒级或更低。
16. **排队时延（d_queue）**：分组在输出链路等待传输的时间，依赖于路由器的拥塞程度，为毫秒级到微秒级。
17. **传输时延（d_trans）**：路由器发送分组到链路的时间，与路由器间距离无关，为毫秒级到微秒级，计算公式为 L/R（L 为分组长度，R 为链路带宽）。
18. **传播时延（d_prop）**：分组从一台路由器传播到另一台路由器的时间，与链路传输速率无关，传播速率与传输介质有关、接近光速，计算公式为 D/S（D 为路由器间距离，S 为传播速率）。
19. **丢包率（Loss）**：网络节点缓冲区中链路容量有限，当缓冲区满时到达分组被丢弃的比例，丢失的包可由前一节点或源端系统重传，也可不重传。
20. **利用率（Utilization）**：信道利用率指某信道在一段时间内被利用的时间占比；网络利用率是全网络的信道利用率的加权平均值。
21. **封装（Encapsulation）**：发送端在数据传输过程中，各层依次为数据添加头部信息的过程。
22. **解封装（De-encapsulation）**：接收端在数据接收过程中，各层依次剥离数据头部信息的过程。
23. **服务数据单元 SDU（Service Data Unit）**：层间传输的数据单元。
24. **协议数据单元 PDU（Protocol Data Unit）**：不同层对应的特定数据单元。

## 【必考简答题预测】

1. **计算机网络系统分层实现的好处有哪些？**

   - 答案：①独立性强；②适应性强；③易于实现和维护；④有利于促进标准化。

2. **计算机网络系统分层实现的原则是什么？**

   - 答案：①层数应适中；②每层功能应明确；③层与层应相互独立；④层间单向引用。

3. **网络协议的定义及其三要素分别是什么？**

   - 答案：网络协议是为进行网络中的数据交换而建立的规则、标准或约定，通信双方需要共同遵守、互相理解。

     其三大要素包括：

     ①语法：数据与控制信息的结构或者格式；

     ②语义：协调双方动作的信息及其含义；

     ③时序：规定动作的时间、事件的实现顺序等。

4. **OSI 参考模型分为哪七层？各层的主要功能是什么？**

   - 答案：OSI 参考模型从下到上依次分为物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。各层主要功能如下：

     ①物理层：规定物理信号、接口、信号形式、速率等，负责比特的传输；

     ②数据链路层：将数据组成帧，实现点到点可靠传输，包含帧同步、差错控制、流量控制、介质访问控制功能；

     ③网络层：解决分组路由以及异构网络互联问题，负责寻址定位、路由选择，将分组传给目的主机；

     ④传输层：提供端到端可靠的数据传输，涉及报文传输、流量控制、差错控制、拥塞控制；

     ⑤会话层：进行会话管理、同步控制，支持断点续发功能；

     ⑥表示层：负责数据结构表示、数据转换、加密、压缩；

     ⑦应用层：为应用程序（如 Web、E-mail、Telnet）提供服务。

5. **TCP/IP 参考模型分为哪四层？各层的主要功能是什么？**

   - 答案：TCP/IP 参考模型从下到上依次分为网络接口层、网际层（IP 层）、传输层、应用层。各层主要功能如下：
     - ①网络接口层：与具体物理传输介质无关，未对物理层和数据链路层做出规定，仅定义主机与传输线路之间的接口，描述链路为网际层必须提供的基本功能；
     - ②网际层（IP 层）：解决分组路由以及异构网络互联问题，传送的数据是分组（包），主要协议有 IPv4、IPv6；
     - ③传输层：实现源端和目的端主机上的进程之间的通信，传送的数据是报文或者数据流，主要协议有 TCP、UDP；
     - ④应用层：包含各种应用层协议，如 HTTP/HTTPS、SMTP、DNS 等，为应用程序提供网络服务。

6. **OSI 模型与 TCP/IP 模型的区别有哪些？**

   - 答案：
     - ①层数不同：OSI 模型为 7 层，TCP/IP 模型为 4 层；
     - ②层功能划分不同：TCP/IP 模型的网络接口层包含了 OSI 模型物理层和数据链路层的部分功能，应用层包含了 OSI 模型的表示层与会话层功能；
     - ③设计思想不同：OSI 模型先有模型后设计协议，不局限于特定协议，明确了服务、协议、接口等概念，更具通用性；TCP/IP 模型是对已有协议的描述，实用性更强；
     - ④通信方式支持不同：OSI 模型网络层能够支持无连接和面向连接通信；TCP/IP 模型的网络层仅支持无连接通信；
     - ⑤实现与应用情况不同：OSI 模型从未真正被实现，标准制定周期长，缺少厂家支持，技术实现糟糕，层次功能划分不合理，协议实现复杂、运行效率低；TCP/IP 模型已成为事实标准，是 UNIX 系统的一部分，免费且应用广泛。

7. **什么是数据的封装与解封装？请结合端到端通信实例说明其过程。**

   - 答案：封装是发送端在数据传输过程中，各层依次为数据添加头部信息的过程；解封装是接收端在数据接收过程中，各层依次剥离数据头部信息的过程。实例：主机 A 上的 QQ 向主机 B 上的 QQ 发送 “hello” 消息。
     - ①封装过程：主机 A 的应用层生成 “hello” 消息（应用层数据单元），将其传递给传输层，传输层添加头部 Ht 后形成段（segment），再传递给网络层，网络层添加头部 Hn 后形成分组（packet），接着传递给链路层，链路层添加头部 Hl 后形成帧（frame），最后物理层将帧转换为比特流（bit）在物理介质上传输；
     - ②解封装过程：主机 B 的物理层接收比特流后，传递给链路层，链路层剥离头部 Hl 得到分组，传递给网络层，网络层剥离头部 Hn 得到段，传递给传输层，传输层剥离头部 Ht 得到 “hello” 消息，最后传递给应用层，主机 B 的 QQ 接收并显示该消息。

8. **计算机网络的常用性能指标有哪些？请分别简要说明。**

   - 答案：常用性能指标包括速率、带宽、吞吐量、时延、丢包率、利用率。
     - ①速率：单位时间内主机在数字信道上传送的数据量，也称比特率，单位为 b/s（bps）等；
     - ②带宽：模拟信道中是允许传输信号的频率范围（单位 Hz），数字信道中是单位时间内所能通过的 “最大数据量”（单位 bit/s），一般通信链路带宽越大，数据传输速率越大；
     - ③吞吐量：单位时间内发送者和接收者之间传输的数据量，单位 bps，包括瞬时、平均、有效吞吐量，端到端吞吐量受瓶颈链路限制；
     - ④时延：包括节点时延，节点时延 = 处理时延 + 排队时延 + 传输时延 + 传播时延，分别对应检查比特错误与决定输出链路、等待传输、发送分组到链路、分组在链路中传播的时间；
     - ⑤丢包率：网络节点缓冲区满时到达分组被丢弃的比例；⑥利用率：信道利用率是某信道被利用时间占比，网络利用率是全网络信道利用率的加权平均值。

9. **如何计算端到端的吞吐量？什么是瓶颈链路？**

   - 答案：端到端的吞吐量计算公式为 Min（Rs，Rc）（Rs 为发送端速率，Rc 为接收端速率）；当存在多条链路共享容量时，如 10 条连接共享容量为 R 的链路，端到端吞吐量为 min（Rc，Rs，R/10）。瓶颈链路是指端到端路径上制约吞吐量的链路，通常发送端速率 Rs 或接收端速率 Rc（接入网）易成为瓶颈链路。

10. **节点时延由哪几部分组成？各部分的影响因素是什么？**

    - 答案：节点时延由处理时延（d_proc）、排队时延（d_queue）、传输时延（d_trans）、传播时延（d_prop）四部分组成。
      - ①处理时延：影响因素包括检查比特错误的复杂度、决定输出链路的决策效率等，通常为微秒级或更低；
      - ②排队时延：影响因素主要是路由器的拥塞程度，为毫秒级到微秒级；
      - ③传输时延：影响因素为分组长度（L）和链路带宽（R），计算公式为 L/R，与路由器间距离无关，为毫秒级到微秒级；
      - ④传播时延：影响因素为路由器间距离（D）和传播速率（S），计算公式为 D/S，与链路传输速率无关，传播速率与传输介质有关、接近光速。

11. **计算机网络的发展经历了哪四个阶段？各阶段的主要特点是什么？**

    - 答案：①面向终端的计算机网络（20 世纪 50 年代）：以单个计算机为中心的远程联机系统，结构为终端 -- 通信线路 -- 计算机，特点是集中控制，除中心计算机外，其余终端无自主处理功能，不算真正的计算机网络；②计算机 -- 计算机网络（20 世纪 60 年代）：以 ARPAnet 建成为标志，还有 IBM 的 SNA、DEC 的 DNA 等，特点是分散控制，为多台独立计算机互联的封闭系统，是真正的计算机网络；③开放式标准化网络（20 世纪 80 年代）：出现 ISO 的 OSI 参考模型和 Internet 的 TCP/IP 参考模型，特点是开放式标准化，可使不同厂商生产的计算机网络互联，是计算机网络发展的主方向；④Internet 广泛应用与高速网络技术发展（20 世纪 90 年代至今）：WWW 技术成为 Internet 指数级增长的主要驱动力，出现下一代互联网（如美国的 Internet2、中国的 CNGI、CENI 等），特点是 Web 技术推动 Internet 广泛应用，计算机网络朝着大规模、高性能、高可用、高可靠的方向发展，从人机互联向万物互联演进。

12. **ARPAnet 最终胜出并发展成今天互联网的原因有哪些？给我们带来了什么启示？**

    - 答案：胜出原因：①诞生阶段：有战略背景和传统技术无法解决的重大需求，分组交换的理论 / 技术突破和原型系统实验并举，且有政府的持续支持；②成长壮大阶段：采用简单实用的 TCP/IP 技术路线，以教育和科研的示范网络为起点，具有实验物理学的研究特点，通过 IETF/RFC 开展联合协作的开放式研究，在不断试错中快速成长；③新发展阶段：商业需求成为核心驱动力，技术创新提供重要基础，网络的便捷程度决定用户使用方式和在线时间，网络性能（带宽、延迟、可靠性）决定用户体验。启示：①重大技术突破与实际需求相结合是技术成功的重要基础；②简单实用的技术路线更易推广和落地；③开放式协作研究与持续迭代优化有助于技术的完善和发展；④政府支持、商业驱动、用户体验三者协同能推动网络技术的长期发展。
