# IP Addressing and Network Layer 网络层编址

## 【核心概念定义】

1. **IPv4 地址**：32 位二进制代码，采用点分十进制记法，分为网络地址和主机地址两部分，用于标识异构网络中的主机（或路由器）的每个接口，由 ICANN 分配，全世界唯一。
2. **分类的 IPv4 地址**：将 IPv4 地址按前几位比特分为 A、B、C、D、E 五类，A 类地址首位为 0，网络号 8 位，主机号 24 位；B 类地址前两位为 01，网络号 16 位，主机号 16 位；C 类地址前三位为 110，网络号 24 位，主机号 8 位；D 类地址前四位为 1110，用于组播；E 类地址前四位为 1111，为保留地址。
3. **特殊 IPv4 地址**：主机标识全为 0 的地址为网络地址；主机标识全为 1 的地址为广播地址；255.255.255.255 表示广播地址；0.0.0.0 表示本机地址，可作为源地址，不能作为目的地址；127.0.0.1 表示回送地址。
4. **内网地址**：不会作为公网地址分配，包括 1 个 A 类（10 开头）、16 个 B 类（172.16~172.31 开头）、255 个 C 类（192.168 开头）地址。
5. **子网划分**：将主机地址中的一部分用来标识不同子网，用子网掩码标识 IP 地址中的网络地址 / 子网地址，记为 a.b.c.d/x（x 表示网络 / 子网地址对应比特位个数）或 32 位点分十进制法（x 个 1+ y 个 0，x+y=32），解决分类 IPv4 地址分配不合理和浪费问题。
6. **无分类编址（CIDR）**：消除传统 A、B、C 类地址概念，将 IP 地址中前部任意长度设为网络地址部分（地址前缀），更有效地分配 IPv4 地址空间。
7. **路由聚合**：单个网络前缀通告多个网络，减少路由器转发表的长度，提升路由信息通告的效率。
8. **DHCP 协议**：动态主机配置协议，是实现网络功能的应用层协议，工作在客户端 / 服务器模式，基于 UDP 工作（服务器端口 67，客户端端口 68），允许主机从 DHCP 服务器动态获取 IP 地址，可更新地址有效期，实现即插即用。
9. **NAT（网络地址转换）**：解决 IPv4 地址不足的问题，内部网络所有设备仅使用一个公网 IPv4 地址与外部网络互联，NAT 路由器通过转换表记录（源 IP 地址，端口号）与（NAT 的 IP 地址，新端口号）的映射关系，实现报文地址转换。
10. **IPv4 协议**：无连接的协议，是互联网的核心，用于实现异构网络互联，IP 数据报由首部（固定部分 20 字节 + 可变部分）和数据两部分组成。
11. **MTU（最大传输单元）**：一个链路层帧能承载的最大数据量，不同链路层协议的 MTU 不同，严格限制 IP 分组的长度。
12. **IPv6**：IPv4 的后继版本，地址空间为 128 位，首部固定长度 40 字节，不允许路由器进行分片，只在源端进行分片，旨在解决 IPv4 地址短缺、缺乏服务质量保障等问题。
13. **双协议栈**：IPv6 过渡策略之一，IPv6 系统能够接收和转发 IPv4 分组，并且能够为 IPv4 分组选择路由，实现逐步演进和向后兼容。
14. **隧道技术**：IPv6 过渡策略之一，将 IPv6 数据报封装在 IPv4 数据报中，在 IPv4 网络中传输，实现 IPv6 网络间的通信。

## 【必考简答题预测】

1. **问题**：IPv4 地址的特点有哪些？

   - **答案**：（1）每个 IP 地址都由网络地址和主机地址两部分组成；（2）IP 地址是标志一台主机（或路由器）和一条链路的接口；（3）集线器或交换机连接起来的若干个局域网仍为一个网络；（4）在 IP 地址中，所有分配到网络地址的网络都是平等的。

2. **问题**：分类的 IPv4 地址中，A、B、C 类地址的最大可指派网络数、第一个和最后一个可指派网络号以及每个网络中最大主机数分别是多少？
- **答案**：
 | 网络类别 | 最大可指派的网络数 | 第一个可指派的网络号 | 最后一个可指派的网络号 | 每个网络中最大主机数 |
 | --- | --- | --- | --- | --- |
 | A | 126（2^7 – 2） | 1 | 126 | 16777214（2^24 - 2） |
 | B | 16383（2^14 – 1） | 128.1 | 191.255 | 65534（2^16 - 2） |
 | C | 2097151（2^21 – 1） | 192.0.1 | 223.255.255 | 254（2^8 - 2） |


注：A 类网络地址中，网络地址 0 和 127 是保留地址，不指派；B 类网络地址中，网络地址 128.0 是被 IANA 保留的，不指派（采用无分类编址 CIDR 时可以指派）；C 类网络地址中，网络地址 192.0.0 是被 IANA 保留的，不指派（采用无分类编址 CIDR 时可以指派）；指派主机地址时，要扣除全 0 和全 1 的地址。


3. **问题**：子网掩码的两种表达方式是什么？子网划分的作用是什么？

   - **答案**：子网掩码的两种表达方式：（1）记为 a.b.c.d/x，其中 x 表示网络 / 子网地址对应比特位个数；（2）用 32 位的点分十进制法表示，x 个 1 + y 个 0（x+y=32），其中 x 表示网络 / 子网地址对应比特位个数，y 表示主机地址对应比特位个数。子网划分的作用是解决分类的 IPv4 地址设计不合理导致的 IP 地址不够分配和浪费问题，将主机地址中的一部分用来标识不同子网，提高 IP 地址利用率。

4. **问题**：无分类编址 CIDR 的主要作用是什么？三个特殊的 CIDR 地址块分别是什么，有何特点？

   - **答案**：CIDR 的主要作用是消除传统的 A 类、B 类、C 类地址概念，更加有效地分配 IPv4 地址空间。三个特殊的 CIDR 地址块：（1）/32：点分十进制为 255.255.255.255，就是一个 IP 地址，用于标识路由器；（2）/31：点分十进制为 255.255.255.254，只有两个 IP 地址，其主机号分别为 0 和 1，用于点对点链路，不需要主机地址，不推荐使用；（3）/0：点分十进制为 0.0.0.0，IP 地址也是全 0（即 0.0.0.0/0），用于默认路由。

5. **问题**：路由聚合的作用是什么？请举例说明路由聚合的过程。

   - **答案**：路由聚合的作用是单个网络前缀通告多个网络，减少路由器转发表的长度，提升路由信息通告的效率。举例：聚合前有 16 个 C 类地址（192.24.0.0~192.24.15.0），地址掩码为 255.255.255.0，路由表中需要 16 个路由项目；聚合后，聚合为 1 个地址 192.24.0.0/20，地址掩码为 255.255.240.0，路由表中只需 1 个路由项目。

6. **问题**：获取 IP 地址的方式有哪些？各自的适用场景是什么？

   - **答案**：获取 IP 地址的方式有静态设定和动态获取两种。（1）静态设定：从管理员处申请固定 IP 地址，手工设定，适用于路由器、服务器等需要固定 IP 地址的设备；（2）动态获取：使用 DHCP 协议，当主机加入 IP 网络时，允许主机从 DHCP 服务器动态获取 IP 地址，可更新所分配 IP 地址的有效期，适用于普通终端设备，能有效利用 IP 地址，方便移动主机的地址获取。

7. **问题**：DHCP 协议的工作过程是什么？

   - **答案**：

     （1）DHCP 服务器发现：主机广播 DHCP 发现报文（UDP 报文，端口 67，源 IP 0.0.0.0，目的 IP 255.255.255.255）；

     （2）DHCP 服务器提供：DHCP 服务器广播 DHCP 提供报文（含有发现报文 ID、IP 地址、子网掩码、IP 地址有效时间等）给所有主机；
     
     （3）主机请求 IP 地址：主机向选中的 DHCP 服务器发送 DHCP 请求报文，并回显配置参数；
     
     （4）DHCP 服务器发送 IP 地址：DHCP 服务器发送 DHCP 应答报文进行确认。DHCP 服务不仅返回客户机所需的 IP 地址，还包括第一跳路由器 IP 地址（默认网关）、本地 DNS 服务器 IP 地址、子网掩码等。

8. **问题**：NAT 的作用和工作原理是什么？NAT 存在哪些争议？

   - **答案**：NAT 的作用：

     （1）解决 IPv4 地址不足的问题，内部网络所有设备仅使用一个公网 IPv4 地址与外部网络互联；

     （2）内部网络设备地址的更换不需要通知外部网络；

     （3）更换 ISP 时，无需改变内部网络设备的 IP 地址；

     （4）提升安全性，内部网络设备对外部网络而言不可见、不可访问。

   - 工作原理：NAT 路由器对外界的行为如同具有单一 IP 地址的单一设备，把每一个发送报文的（源 IP 地址，端口号）替换为（NAT 的 IP 地址，新端口号），并在 NAT 转换表中记录映射关系；接收报文时，根据 NAT 转换表将目的字段中的（NAT 的 IP 地址，新端口号）替换为相应的（源 IP 地址，端口号）。

   - NAT 的争议：

     （1）违反了网络分层原则，端口号是用于进程寻址，而非主机寻址，路由器应该只能处理网络层分组；

     （2）违反端到端原则；

     （3）可能导致 P2P 应用不可用（需通过 NAT 穿越实现客户端和 NAT 后面的服务器建立连接）。

9. **问题**：IPv4 数据报的首部由哪几部分组成？固定部分的各字段含义是什么？

   - **答案**：IPv4 数据报的首部由固定部分（20 字节）和可变部分（可选字段 + 填充）组成。固定部分各字段含义：

     （1）版本：占 4 位，表示 IP 协议的版本，IPv4 协议版本号为 4；

     （2）首部长度：占 4 位，可表示的最大数值是 15 个单位（一个单位为 4 字节），因此 IP 的首部长度的最大值是 60 字节；

     （3）区分服务：占 8 位，表示获得的服务类型，仅在使用区分服务（DiffServ）时起作用，一般情况下不使用；

     （4）总长度：占 16 位，指首部和数据之和的长度，单位为字节，数据报的最大长度为 65535 字节，且总长度不能超过最大传输单元 MTU；

     （5）标识：占 16 位，是一个计数器，用来表示 IP 数据报的标识；

     （6）标志：占 3 位，目前只有后两位有意义，最低位 MF（More Fragment）=1 表示后面还有分片，MF=0 表示最后一个分片；中间位 DF（Don't Fragment）=0 时才允许分片；

     （7）片偏移：占 13 位，表示较长分组在分片后某片在原分组中的相对位置，以 8 个字节为偏移单位；

     （8）生存时间（TTL）：占 8 位，表示数据报在网络中可通过的路由器数的最大值；

     （9）协议：占 8 位，表示此数据报携带的数据部分使用何种协议，以便目的主机的 IP 层将数据部分上交给上层处理；

     （10）首部检验和：占 16 位，只检验数据报的首部，不检验数据部分，采用简单的校验和计算方法；

     （11）源地址和目的地址：各占 32 位，分别表示数据报的发送端和接收端的 IP 地址。

10. **问题**：IPv4 数据报分片的原因是什么？分片和重组的特点是什么？

    - **答案**：分片原因：不同链路层协议的 MTU 不同，大 IP 分组的长度超过链路层帧的 MTU 时，需要进行分片。分片和重组的特点：（1）一个分组变成多个分组；（2）仅在最终的目的端进行重组；（3）IP 分组首部中有标识、标志、片偏移字段用于分片和重组；（4）原始报文和分片报文具有相同的 IP 报文标识；（5）IPv4 分组在传输途中可以多次分片，分片长度必须是 8B 的整数倍；（6）源端系统、中间路由器（可通过标志位 DF 位设定是否允许路由器分片）可进行分片。

11. **问题**：为什么每经过一个路由器都要重新计算校验和？

    - **答案**：因为每当数据报经过一个路由器时，其IP首部中的一些字段几乎必然会发生改变，而这些改变会使原有的首部检验和失效，因此必须重新计算以确保数据的完整性。

12. **问题**：IPv6 产生的动机是什么？

    - **答案**：（1）32 位地址空间不够用（2011 年 2 月分配完），CIDR 和 NAT 都无法从根本上解决地址短缺问题；（2）提高路由器处理和转发速度（简化报文首部字段）；（3）IPv4 缺乏服务质量保障机制。

13. **问题**：IPv6 地址的表示方法有哪些？

    - **答案**：（1）冒号十六进制记法：每 4bit 用一个十六进制值表示，每四个十六进制值为一组，之间用 “:” 分隔，如 686E:8C64:FFFF:FFFF:0:1180:096A:FFFF；（2）零压缩：一连串连续的零可以用一对冒号表示，如 FF05:0:0:0:0:0:0:00B3 可写成 FF05::00B3；（3）内嵌 IPv4 地址格式：如 0:0:0:0:0:0:211.65.59.34 或::211.65.59.4。

14. **问题**：IPv6 报文格式与 IPv4 相比有哪些主要变化？

    - **答案**：（1）地址空间从 32 位扩展到 128 位；（2）首部固定长度从 20 字节变为 40 字节；（3）取消了首部长度字段；（4）服务类型字段改为流量类型字段；（5）总长度字段改为有效载荷长度字段；（6）TTL 字段改为跳数限制字段；（7）协议类型字段改为下一个首部字段；（8）取消了标识、标志、片偏移、检验和字段；（9）取消了选项字段，而用扩展首部来实现选项功能；（10）不允许路由器进行分片，只在源端进行分片。

15. **问题**：从 IPv4 到 IPv6 的过渡策略有哪些？各自的原理是什么？

    - **答案**：过渡策略有双协议栈和隧道技术两种。（1）双协议栈：原理是 IPv6 系统必须能够接收和转发 IPv4 分组，并且能够为 IPv4 分组选择路由，实现逐步演进和向后兼容，使得 IPv4 和 IPv6 网络可以共存并通信；（2）隧道技术：原理是将 IPv6 数据报封装在 IPv4 数据报中，在 IPv4 网络中传输，当 IPv6 数据报到达 IPv4 网络的另一端时，再解封装出 IPv6 数据报，实现 IPv6 网络间通过 IPv4 网络的通信。

16. **问题**：IPv6 的特点和优势有哪些？

    - **答案**：（1）无限的地址空间（2^128），有利于后续业务拓展；（2）层次化地址结构，利于路由快速查找、路由聚合，缩减 IPv6 路由表大小；（3）增强组播和流控，8BIT QOS、20BIT 流标签促进互联网多媒体应用提供平台；（4）即插即用，无状态地址自动配置，简化终端配置；（5）结构化地址架构，地址分配更规范，各大洲各国区分明显；（6）简化与扩展，简化报文头，提高效率，通过扩展包头支持新应用；（7）面向移动性，5G 场景优势突出，性能飞跃提升，对移动网络实时通信有较大改进；（8）内嵌安全 IPSec，更安全可靠，真实源地址认证等保证端到端安全。
