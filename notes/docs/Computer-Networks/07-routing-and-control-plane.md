# 路由算法

路由算法用于确定分组从发送方经过多个路由器到达接收方的路径。“好”路径可以指最低开销、最快传输或最低拥塞的路径。

## 路由算法的分类

路由算法主要有两类分类方式：

（1）按信息获取范围分类：

- 集中式路由选择算法：每个路由器都具有连通性和链路开销方面的完整信息，如链路状态（LS）算法，每个节点具有全局网络状态信息。


- 分布式路由选择算法：每个路由器仅有与其物理连接的邻居节点及链路开销信息，通过与相邻节点交换信息，进行迭代计算，获得最低开销路径，如距离向量（DV）算法，每个节点维护到网络中所有其他节点的开销 / 距离向量。


（2）按路由是否自动调整分类：

- 静态路由选择算法：路由随时间变化非常缓慢，通常人工进行调整。


- 动态路由选择算法：路由随着网络流量负载或拓扑的改变而自动调整，优点是对网络变化反应快，不足是存在路由选择循环、路由振荡等问题。


此外，动态路由算法还可分为负载敏感算法（绕开拥塞链路，易产生路由振荡）和负载迟钝算法（如 RIP、OSPF、BGP）。

## 链路状态路由与 Dijkstra 算法

（1）链路状态路由算法的核心思想：每个节点获得整个网络拓扑和所有链路开销，通过链路状态广播算法发布自身到邻居的链路开销（带宽、延迟、跳数、负载等），使所有节点都具有该网络的统一、完整视图，再基于 Dijkstra 算法计算从源节点到其他所有节点开销最小的路径，最终根据算法结果构建每一个路由器的转发表。

（2）Dijkstra 算法步骤：

① 初始化：N' = {u}（N' 为最小开销路径已知的目的节点集合，初始为源节点 u）；对于所有节点 v，若 v 与 u 相邻，则 D (v) = c (u,v)（D (v) 为从源节点到目的节点 v 的路径开销，c (u,v) 为节点 u 到 v 的链路开销），否则 D (v) = ∞；p (v) 为从源节点到 v 沿着当前最低开销路径的前一节点（v 的邻居）。

② 循环：找到不在 N' 中且 D (w) 最小的节点 w，将 w 加入 N'；对所有与 w 相邻且不在 N' 中的节点 v，更新 D (v) = min (D (v), D (w) + c (w,v))，直到所有节点都在 N' 中。

## 距离向量路由与 Bellman-Ford 方程

（1）核心思想：每个节点向它的邻居节点发送自己的距离向量 Dx (y)（Dx (y) 为从节点 x 到节点 y 的最小开销路径的开销）；当节点 x 到邻居的链路开销发生变化或者从邻居接收到新的距离向量时，该节点将根据 Bellman-Ford 公式更新自己的距离向量；如果节点 x 的距离向量发生改变，则继续向它的邻居节点发送更新后的距离向量，最终 Dx (y) 会收敛到实际的最小开销 dx (y)。

（2）Bellman-Ford 方程：Dx (y) = min {c (x,m) + Dm (y)}，其中 m 为 x 的邻居节点，c (x,m) 为 m 到 x 的链路开销。

## 链路状态与距离向量的区别

两者区别主要体现在以下方面：

（1）网络状态信息的交换范围：DV 算法仅在邻居间交换信息；LS 算法则是全网扩散信息。

（2）网络状态信息的可靠性：DV 算法的信息是部分道听途说；LS 算法的信息是节点自己测量的。

（3）算法的健壮性：DV 算法是计算结果传递，健壮性差；LS 算法是各自计算，健壮性好。

（4）算法的收敛速度：DV 算法收敛慢，存在无穷计数问题；LS 算法收敛快，但存在路由震荡问题。

## 路由振荡

（1）产生原因：链路开销等于承载的负载，且不对称，导致产生负载敏感的路由振荡。

（2）解决办法：① 使链路开销与负载无关（有些场景不符合实际，需要避开拥塞）；② 每台路由器发送链路通告的时间随机化。

## 无穷计数

（1）产生原因：节点发现本地链路开销增大，算法经过 “多次” 迭代才能收敛。

（2）解决办法：① **毒性逆转**：如果 z 通过 y 到达 x，则向 y 发送一个特殊的 “毒药” 信息，告诉 y 自己到达 x 的距离是无穷大（仅解决 2 个相邻节点无穷计数问题）；② **定义最大度量**：定义一个最大的度量值，当路径长度超过这个值时，就认为网络不可达（在 RIP 中是 16 跳）。

# 路由协议

## 层次路由

（1）动机：① 解决路由表过于庞大导致的存储、查找困难，以及路由信息交互开销大的问题；② 提高路由器查表速度，减少路由表存储空间，需要缩减路由条目；③ 解决**网络扩展性问题**，当网络扩大时，控制路由表条目和路由表存储空间的增长；④ 解决**管理的自治问题**，让网络管理员可以控制和管理自己网络的路由。

（2）基本思路：互联网由大量不同的自治网络系统（AS）互连，AS 是一个管理机构控制之下的网络，内部通常使用相同的路由算法 / 路由协议，使用统一的路由度量，不同 AS 可使用不同路由算法 / 路由协议；自治系统内部使用内部网关路由协议（IGP），自治系统之间使用外部网关路由协议（EGP）；自治系统内还可进一步划分层次（私有自治系统或区域）。

## 自治系统 AS

（1）定义：一个管理机构控制之下的网络。

（2）特点：① 内部通常使用相同的路由算法 / 路由协议，使用统一的路由度量（跳数、带宽、时延等）；② 不同的 AS 可以使用不同的路由算法 / 路由协议；③ 每个 AS 有一个全球唯一的 ID 号（AS ID）。

## IGP 与 EGP

（1）区别：① 适用范围：IGP 用于自治系统内部；EGP 用于自治系统之间。② 协议统一性：IGP 每个自治系统域内可不同；EGP 各自治系统域之间需统一。

（2）典型协议：① IGP：RIP、OSPF、IS-IS、IGRP（Cisco 私有协议，2016 年公开）；② EGP：BGP。

## OSPF

（1）优点：① 开放：路由选择协议规范是公开可用的；② 支持无类域间路由（CIDR）；③ 支持协议报文认证：所有 OSPF 消息都能被鉴别（口令认证、MD5），防止恶意入侵；④ 允许存在多条具有相同开销的路径（RIP 协议仅允许有一条）；⑤ 对单播和多播路由具有较好支持：多播 OSPF（MOSPF）使用 OSPF 的链路数据库；⑥ 支持单个 AS 内的层次 OSPF。

## 层次化 OSPF

（1）结构：两级层次化，包括本地区域和主干区域。

（2）各部分作用：① 本地区域：链路状态信息仅仅在区域内通告，每个节点都有所属区域的详细拓扑；② 主干区域：连接各个本地区域，负责区域间的路由信息传递；③ 区域边界路由器：为流向该区域以外的分组提供路由选择；④ 主干路由器：在主干区域内运行 OSPF 协议；⑤ AS 边界路由器：连接其他 AS，传递 AS 间的路由信息。

## BGP

（1）核心任务：① 从邻居 AS 获得子网可达信息（eBGP）；② 传播子网可达信息给 AS 内的所有路由器（iBGP）；③ 基于可达信息和策略决定到其他网络的 “最好” 路由；④ 允许子网向 Internet 通告自己的存在。

（2）会话类型：eBGP 连接和 iBGP 连接，每对路由器通过使用 **179 端口的半永久 TCP 连接**交换 BGP 消息，iBGP 连接并不总是与物理链路对应。

## BGP 路由与属性

（1）路由组成：route = prefix + attributes（前缀 + 属性）。

（2）重要属性及作用：

- AS-PATH：前缀通告已经通过的 AS 列表，可用来检测和防止通告环路；

- NEXT-HOP：AS-PATH 中起始路由器的接口 IP 地址，指明了沿 AS-PATH 前往下一跳 AS 的域间路由器地址。

## BGP 路由选择

BGP 路由选择策略按以下规则顺序进行选择：

（1）规则 1：选择具有最高本地偏好值（由本地策略决定）的路由。

（2）规则 2：选择具有最短 AS-PATH 的路由（考虑域间开销）。

（3）规则 3：选择具有最近 NEXT-HOP 路由器的路由 —— 热土豆路由（考虑域内开销）。

（4）规则 4：使用 BGP 标识符进行路由选择。

## 热土豆路由

（1）定义：当路由器通过 iBGP 学到能够通过多个本地网关到达目的地时，选择拥有最小域内开销的本地网关，而不必考虑域间路由开销的路由方式。

（2）举例：若 2d 通过 iBGP 学到它能够通过 2a 或者 2c 到达 X，即使通过 2a 到达 X 有更多的 AS 跳数，但如果 2d 到 2a 的域内开销更小，2d 会选择 2a 作为下一跳。

## 域内与域间路由

原因主要包括以下方面：

（1）规模因素：分层路由能够减小路由表，减少路由更新流量。

（2）策略因素：域间路由中策略起主导作用；域内路由由于是单一管理，策略作用不明显。

（3）性能因素：域内路由更多地关注传输性能；域间路由中策略可能掩盖了用户对性能的关注。

（4）管理因素：不同自治系统的管理机构有各自的管理方法和思路，区分域内和域间路由可保障管理的自治性。

# 组播路由

## 组播的作用

（1）动机：当源主机需要向网络中的一组目标用户发送数据（如视频服务器向 90 台主机发送体育直播视频）时，避免单播方式下需发送多个相同数据包导致的网络资源浪费，提高传输效率。

（2）优势：采用组播方式只需发送一次分组到该组用户，路由器负责复制分组，可大大节约网络资源。

## 组播组成员

（1）确定方式：通过 IGMP（Internet Group Management Protocol）协议实现，IGMP 是路由器与主机之间的组成员关系协议，路由器通过与主机交互了解到从它的某个端口可以到达哪些组的成员。

（2）相关地址：组播地址（D 类地址），前四位固定为 1110，范围 224.0.0.0~239.255.255.255，其中 224.0.0.0 至 224.0.0.255 为保留地址，仅用于目的地址，不能用于源地址。

## 组播路由生成树

（1）基于源点树（Shortest Path Tree, SPT）：

- 特点：以组播源为根，到每个组成员节点的路径是最短路径；但组播源很多时，路由器需生成多棵树，开销大。
- 对应协议：链路状态路由算法对应的多播开放最短通路优先协议 MOSPF；距离向量路由算法对应的距离向量多播路由协议 DVMRP、协议无关多播 - 稠密模式（PIM-DM）。

（2）基于核心树（Rendezvous Point Tree, RPT）：

- 特点：多个组播源共享一棵树，每个路由器只需要保存一棵树，大大节省存储、计算、消息发送开销；但对某一组播源来说，路径不一定是最优的。
- 对应协议：协议无关多播 - 稀疏方式（PIM-SM）、特定源组播（PIM-SSM）。

## 组播中的隧道技术

（1）定义：隧道技术是将组播数据报封装在单播 IP 数据报中，使组播数据报能够穿越不支持组播的网络的技术。

（2）作用：解决组播数据报在不支持组播的网络中的传输问题，保障组播数据能够到达目标组播成员，构建组播主干（MBone）。
