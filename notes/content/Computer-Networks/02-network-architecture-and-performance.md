# 网络协议

**协议**是为进行网络中的数据交换而建立的规则、标准或约定。通信双方必须共同遵守、互相理解，才能向上一层提供服务。

协议由三部分组成：

- **语法**：数据与控制信息的结构或格式；
- **语义**：协调双方动作的信息及其含义；
- **时序**：动作的时间和事件的执行顺序。

# 分层、服务与接口

**层（Layer）**是开放系统的逻辑划分。对 N 层而言，N+1 层是上一层，N-1 层是下一层。

- **层功能**：本层对内实现的功能；
- **层服务**：本层向上一层提供的功能，N 层服务 = N 层功能 + N-1 层服务；
- **接口**：相邻层之间的边界，定义下层向上层提供的服务原语；
- **网络体系结构**：计算机网络各层及其协议的集合。

分层使各层相对独立，便于实现、维护和标准化，也更容易适应技术变化。层数应适中，每层功能明确，层间相互独立并单向引用。

# OSI 参考模型

OSI（Open System Interconnection）由 Day 和 Zimmermann 于 1983 年提出，后被 ISO 定为国际标准。自下而上分为七层：

1. **物理层**：规定物理信号、接口、信号形式和速率，传输比特；
2. **数据链路层**：将数据组成帧，实现点到点可靠传输，包含帧同步、差错控制、流量控制和介质访问控制；
3. **网络层**：解决分组路由和异构网络互联，完成寻址定位和路由选择；
4. **传输层**：提供端到端可靠传输，涉及报文传输、流量控制、差错控制和拥塞控制；
5. **会话层**：进行会话管理和同步控制，支持断点续发；
6. **表示层**：负责数据表示、转换、加密和压缩；
7. **应用层**：为 Web、E-mail、Telnet 等应用程序提供服务。

# TCP/IP 参考模型

TCP/IP 参考模型由 ARPANET 采用，以 TCP 和 IP 协议命名，Vint Cerf 和 Bobert Kahn 于 1974 年提出。自下而上分为四层：

1. **网络接口层**：定义主机与传输线路之间的接口，描述链路为网际层必须提供的基本功能；
2. **网际层（IP 层）**：解决分组路由和异构网络互联，传送分组，主要协议为 IPv4、IPv6；
3. **传输层**：实现源端和目的端主机上进程之间的通信，传送报文或数据流，主要协议为 TCP、UDP；
4. **应用层**：包含 HTTP/HTTPS、SMTP、DNS 等协议，为应用程序提供网络服务。

TCP/IP 的网络接口层对应 OSI 的物理层和数据链路层，应用层包含 OSI 的表示层和会话层功能。OSI 先定义模型再设计协议，明确服务、协议与接口；TCP/IP 是对已有协议的描述，实用性更强。OSI 网络层可支持无连接和面向连接通信，TCP/IP 网络层仅支持无连接通信。TCP/IP 已成为事实标准。

# 封装、解封装与数据单元

**封装**是发送端各层依次添加头部信息的过程；**解封装**是接收端各层依次剥离头部信息的过程。

以主机 A 上的 QQ 向主机 B 上的 QQ 发送 `hello` 为例：应用层数据依次经过传输层、网络层和链路层，分别添加首部，形成段（segment）、分组（packet）和帧（frame）；物理层将帧转换为比特流传输。接收端按相反顺序解封装，最终将 `hello` 交给应用层。

**SDU（Service Data Unit）**是层间传输的数据单元，**PDU（Protocol Data Unit）**是某层协议处理后的特定数据单元。

# 网络性能指标

- **速率（Rate）**：单位时间内在数字信道上传送的数据量，即比特率，单位 `b/s`、`bps`、`Kb/s`、`Mb/s`、`Gb/s`；
- **带宽（Bandwidth）**：模拟信道中是允许传输信号的频率范围，单位 Hz；数字信道中是单位时间内可通过的最大数据量，单位 bit/s；
- **吞吐量（Throughput）**：单位时间内发送者和接收者之间实际传输的数据量，包括瞬时、平均和有效吞吐量；
- **瓶颈链路**：端到端路径上制约吞吐量的链路。端到端吞吐量为 $\min(R_s,R_c)$；若 10 条连接共享容量为 $R$ 的链路，则为 $\min(R_s,R_c,R/10)$；
- **时延（Delay）**：节点时延为

$$
d_{nodal}=d_{proc}+d_{queue}+d_{trans}+d_{prop}
$$

  其中处理时延用于检查比特错误和决定输出链路；排队时延取决于拥塞程度；传输时延为 $d_{trans}=L/R$，与路由器间距离无关；传播时延为 $d_{prop}=D/S$，与链路传输速率无关；
- **丢包率（Loss）**：节点缓冲区满时到达分组被丢弃的比例；
- **利用率（Utilization）**：信道在一段时间内被利用的时间占比；网络利用率是全网络信道利用率的加权平均值。

# 计算机网络的发展

1. **面向终端的计算机网络（20 世纪 50 年代）**：终端 -- 通信线路 -- 中心计算机，集中控制，终端没有自主处理功能；
2. **计算机 -- 计算机网络（20 世纪 60 年代）**：以 ARPANET 建成为标志，多台独立计算机互联，分散控制；
3. **开放式标准化网络（20 世纪 80 年代）**：出现 OSI 和 TCP/IP，推动不同厂商网络互联；
4. **Internet 广泛应用与高速网络技术发展（20 世纪 90 年代至今）**：WWW 推动 Internet 广泛应用，网络向大规模、高性能、高可用和高可靠发展。

ARPANET 采用简单实用的 TCP/IP 技术路线，以教育和科研网络为起点，通过 IETF/RFC 的开放协作持续演进，最终发展为今天的互联网。
