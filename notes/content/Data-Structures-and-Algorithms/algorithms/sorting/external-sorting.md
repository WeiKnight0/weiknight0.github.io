# External Sorting 外部排序

待排序数据无法一次装入内存时，需要借助外存完成排序。外存访问远慢于内存计算，因此外部排序的主要优化目标是减少读写外存的次数。

## 外部归并排序

外部归并分为两个阶段：

1. **生成初始归并段**：分批读入能装入内存的数据，在内存中排序后写回外存，形成多个有序段。
2. **多路归并**：每轮同时将 $k$ 个有序段合并成一个更长的有序段，直到只剩一个有序文件。

若初始归并段数为 $r$，每次做 $k$ 路归并，归并趟数为：

$$\lceil\log_k r\rceil$$

增大归并路数或减少初始归并段数都能减少归并趟数，但增大 $k$ 会占用更多输入缓冲区。

## 败者树

$k$ 路归并需要反复从 $k$ 个当前记录中选出最小值。直接比较需要 $O(k)$ 时间，败者树将它降为 $O(\log k)$。

败者树是一棵完全二叉树，每个非叶节点记录两个孩子中的败者，最终胜者单独保存。输出最小记录后，只需沿该记录到根的路径重新比较。

## 置换选择

普通方法生成的初始归并段长度受内存容量限制。置换选择可以生成平均长度约为内存工作区容量两倍的初始归并段。

工作区中每次输出不小于当前归并段上一记录的最小值，然后读入新记录。新记录若小于已输出值，则冻结到下一个归并段。当工作区所有记录都被冻结时，当前归并段结束。

## 最佳归并树

初始归并段长度不等时，应优先合并较短的归并段，使总读写记录数最少。这与哈夫曼树的构造原理相同。

做严格 $k$ 路归并时，若初始归并段数不满足 $(r-1)\bmod(k-1)=0$，需要补入权值为 $0$ 的虚段，使归并树保持严格 $k$ 叉结构。
