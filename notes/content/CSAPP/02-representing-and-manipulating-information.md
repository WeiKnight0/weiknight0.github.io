# 1. 信息存储

**虚拟内存**：程序将内存视为一个庞大的字节数组。
**字节（Byte）**：最小的可寻址内存单位，1 字节 = 8 位（bit）。每个字节都有唯一的**地址**。

## 1.1 十六进制表示

* 1 个十六进制位 = 4 个二进制位；1 个字节（8 位）可表示为 2 位十六进制数。
* C 语言中以 `0x` 或 `0X` 开头，字符 `A`\~`F` 对应十进制 10~15。
* **示例**：`0x2A` $\rightarrow$ 二进制 `0010 1010` $\rightarrow$ 十进制 42。

## 1.2 字长与数据大小

* **字长（Word Size）**：指明指针数据的标称大小，决定虚拟地址空间的最大范围。字长为 $w$ 位的机器，虚拟地址范围为 $0 \sim 2^w - 1$（如 64 位机器的指针占 8 字节）。
* **类型与机器码**：机器代码不包含数据类型信息，同一段字节如何解析完全取决于操作它的指令。

**C 语言常见数据类型大小（单位：字节）**：

| C 数据类型 | 32 位系统 | 64 位系统 | 说明 |
| --- | --- | --- | --- |
| `char` | 1 | 1 | 始终为 1 字节 |
| `short` | 2 | 2 | 固定 |
| `int` | 4 | 4 | 固定 |
| `long` | 4 | **8（Linux）/ 4（Windows）** | 随平台数据模型变化 |
| `long long` | 8 | 8 | C 标准保证至少 8 字节 |
| `float` / `double` | 4 / 8 | 4 / 8 | IEEE 754 浮点数 |
| 指针（如 `char *`） | 4 | 8 | **等于机器字长** |

* **固定宽度类型**：为避免跨平台大小不一致，可使用 `<stdint.h>` 中的 `int32_t`、`uint64_t` 等类型；极值宏（如 `INT_MAX`）定义在 `<limits.h>` 中。

## 1.3 寻址与字节顺序

* **对象的地址**：多字节对象占用连续的内存字节，其地址为**所占字节中的最小地址**。
* **字节序**：指多字节对象在内存中的排列顺序。
* **小端序（Little Endian）**：**最低有效字节**存放在**最低地址**（x86 架构使用）。
* **大端序（Big Endian）**：**最高有效字节**存放在**最低地址**（网络协议常用）。


* **示例**：假设 32 位整数 `0x12345678` 存放在起始地址 `0x100`（最高有效字节为 `12`，最低有效字节为 `78`）：

| 地址 | `0x100` | `0x101` | `0x102` | `0x103` |
| --- | --- | --- | --- | --- |
| **小端序** | `78` | `56` | `34` | `12` |
| **大端序** | `12` | `34` | `56` | `78` |

## 1.4 字符串与代码的表示

* **字符串**：C 语言中字符串是以空字符 `\0`（ASCII 码为 0）结尾的字符数组。因为每个字符独立占单字节（ASCII）或按固定顺序编码（UTF-8），**文本数据不受字节序和字长影响**，跨平台兼容性强。
* **机器代码**：指令在内存中也是字节序列。不同处理器架构（指令集）和操作系统使用不同的编码规则，因此**二进制机器码通常不能跨平台直接运行**。

## 1.5 布尔代数与位向量

* **位向量**：长度为 $w$ 的 0/1 序列。
* **表示有限集合**：可以用位向量编码集合 $\{0, 1, \dots, w-1\}$，某位为 1 表示对应下标的元素在集合中。
* **示例**：8 位向量 `0110 1001`（从右往左编号为 0~7，为 1 的位置是第 0、3、5、6 位）表示集合 $A = \{0, 3, 5, 6\}$。两个位向量的按位与 `&`、按位或 `|` 分别对应集合的**交集**和**并集**。

## 1.6 C 语言的位级运算

* **运算符**：按位取反 `~`、按位与 `&`、按位或 `|`、按位异或 `^`，对操作数的每一位独立计算。
* **掩码（Mask）操作**：通过特定位模式筛选或修改指定位。
* `x & 0xFF`：提取 `x` 的最低有效字节，其余位置 0（如 `0x89ABCDEF & 0xFF` 得到 `0x000000EF`）。
* `~0`：生成全 1 的掩码（自适应数据类型宽度，比写死 `0xFFFFFFFF` 更通用）。



## 1.7 C 语言的逻辑运算

* **运算符**：逻辑与 `&&`、逻辑或 `||`、逻辑非 `!`。
* **与位运算的三个区别**：
1. **真值判断**：所有非零参数都视为 `True`，只有 0 视为 `False`。
2. **返回值**：结果只能是 `1` 或 `0`（例如 `!0x41` 结果为 `0`，而 `~0x41` 结果为 `0xBE`）。
3. **短路求值**：若左侧表达式已能确定最终结果，右侧表达式**不会执行**（例如 `p && *p++` 中，若指针 `p` 为空，则不会发生解引用）。



## 1.8 C 语言的移位运算

* **左移（`x << k`）**：向左移动 $k$ 位，丢弃最高的 $k$ 位，右端补 $k$ 个 0。
* **右移（`x >> k`）**：向右移动 $k$ 位，丢弃最低的 $k$ 位，左端补位方式分两种：
* **逻辑右移**：左端补 $k$ 个 0（**无符号数**固定使用）。
* **算术右移**：左端补 $k$ 个**最高有效位（符号位）的值**，**有符号数**通常使用。


* **示例**（假设 8 位数据 `x = 1001 0101`，最高位为 1）：
* 左移 4 位 `x << 4`：`0101 0000`
* 逻辑右移 4 位：`0000 1001`（补 0）
* 算术右移 4 位：`1111 1001`（补符号位 1）


* **注意**：移位量 $k$ 必须满足 $0 \le k < w$（$w$ 为数据类型位宽），否则行为未定义；加减法优先级高于移位运算（`1 << 2 + 3` 等价于 `1 << (2 + 3)`）。

# 2. 整数表示
设位向量为 $\vec{x} = [x_{w-1}, x_{w-2}, \dots, x_0]$，总位宽为 $w$。

| 符号 | 含义 |
| --- | --- |
| $B2U_w$ | 二进制转无符号数 |
| $B2T_w$ | 二进制转补码 |
| $B2O_w$ | 二进制转反码 |
| $B2S_w$ | 二进制转原码 |
| $U2B_w$ | 无符号数转二进制 |
| $T2B_w$ | 补码转二进制 |
| $T2U_w$ | 补码转无符号数 |
| $U2T_w$ | 无符号数转补码 |
| $UMin_w = 0$ | 最小无符号值 |
| $UMax_w = 2^{w}-1$ | 最大无符号值 |
| $TMin_w = - 2^{w-1}$ | 最小补码值 |
| $TMax_w$ = 2^{w-1} -1 $ | 最大补码值 |
| $+^u_w$ | 无符号加法 |
| $-^u_w$ | 无符号数取反 |
| $+^t_w$ | 补码加法 |
| $-^t_w$ | 补码取反 |
| $*^u_w$ | 无符号乘法 |
| $*^t_w$ | 补码乘法 |

## 2.1 无符号编码与补码编码

* **无符号编码（$B2U_w$）**：所有位均为正权值。

$$
B2U_w(x) = \sum_{i=0}^{w-1} x_i 2^i
$$


* **补码编码（$B2T_w$）**：**最高位（符号位）权值为负**（$-2^{w-1}$），其余位权值为正。$x_{w-1}=1$ 表示负数，$x_{w-1}=0$ 表示非负数。

$$
B2T_w(x) = -x_{w-1}2^{w-1} + \sum_{i=0}^{w-2} x_i 2^i
$$


**核心属性对比**：

| 属性 | 无符号数（Unsigned） | 补码（Two's-complement） |
| --- | --- | --- |
| **最小值** | $UMin_w = 0$（全 `0`） | $TMin_w = -2^{w-1}$（`100...0`） |
| **最大值** | $UMax_w = 2^w - 1$（全 `1`） | $TMax_w = 2^{w-1} - 1$（`011...1`） |
| **$-1$ 的位模式** | 无 | 全 `1`（与 $UMax_w$ 位模式完全相同） |
| **范围特点** | 全部非负，与位模式一一对应 | **不对称**：$\Vert{}TMin_w\Vert{} = TMax_w + 1$（因 $0$ 占据非负半区） |

* **示例**（以 $w=4$ 位向量 `1011` 为例）：
* 无符号解释：$1 \times 8 + 0 \times 4 + 1 \times 2 + 1 \times 1 = 11$
* 补码解释：$-1 \times 8 + 0 \times 4 + 1 \times 2 + 1 \times 1 = -5$

## 2.2 有符号与无符号转换

**基本原则**：相同位宽下强制类型转换，**底层的位模式保持不变**，仅改变解释这些位的方式。

* **补码转无符号（$T2U_w$）**：对于 $TMin_w \le x \le TMax_w$ 的x，非负数不变，负数加上 $2^w$。

$$
T2U_w(x) = \begin{cases} x, & x \ge 0 \\ x + 2^w, & x < 0 \end{cases}
$$

* **无符号转补码（$U2T_w$）**：对于 $0 \le x \le UMax_w$ 的 $x$，小于等于 $TMax_w$ 不变，大于 $TMax_w$ 减去 $2^w$。

$$
U2T_w(u) = \begin{cases} u, & u
\le TMax_w \\ u - 2^w, & u > TMax_w \end{cases}
$$

**隐式转换规则**：当有符号数与无符号数在表达式中混合运算（含比较运算）时，C 语言会将**有符号数隐式转换为无符号数**。
**示例**：
* 表达式 `-1 < 0U`：`-1` 被转换为无符号最大值 $UMax$，因此 `-1 < 0U` 的求值结果为 **`0`（假）**。
* 涉及 `sizeof` 返回值或 `strlen()` 的 `size_t` 类型均为无符号数（如当 `length == 0` 时，`length - 1` 会变成极大的正数 $UMax$，而非 `-1`）。


## 2.3 位宽扩展与截断

### 2.3.1 位宽扩展
**位宽扩展**是将$w$ 位数字扩展为 $w' = w + k$ 位，数值保持不变。

设原位向量为 $\vec{x} = [x_{w-1}, x_{w-2}, \dots, x_0]$，位宽为 $w$。

* **零扩展（无符号数）**：在高位补 $k$ 个 $0$，新位向量 $\vec{u}' = [0, \dots, 0, x_{w-1}, \dots, x_0]$。

$$
B2U_{w+k}(\vec{u}') = B2U_w(\vec{x})
$$

* **符号扩展（补码数）**：在高位补 $k$ 个最高有效位 $x_{w-1}$，新位向量 $\vec{x}' = [x_{w-1}, \dots, x_{w-1}, x_{w-1}, \dots, x_0]$。

$$
B2T_{w+k}(\vec{x}') = B2T_w(\vec{x})
$$

* **混合转换顺序**：若同时改变位宽与符号性（如 `short` 转 `unsigned`），C 标准规定**先扩展位宽，再改变符号解释**。

* **示例**：将 4 位补码 `-5`（`1011`）符号扩展为 8 位，高 4 位复制符号位 `1` 得 `1111 1011`，其值仍为 $-128 + 64 + 32 + 16 + 8 + 2 + 1 = -5$。

### 2.3.2 数字截断
**数字截断** 是将 $w$ 位向量 $\vec{x} = [x_{w-1}, x_{w-2}, \dots, x_0]$ 变为$k$ 位，$k < w$，直接丢弃高 $w - k$ 位，得到 $\vec{x}' = [x_{k-1}, x_{k-2}, \dots, x_0]$）：
* **无符号数截断**：结果等价于对 $2^k$ 取模。令 $u = B2U_w(\vec{x})$，截断后新值 $u' = B2U_k(\vec{x}')$：

$$
u'= B2U_k(\vec{x}') = u \bmod 2^k = B2U_w(\vec{x}) \bmod 2^k
$$


* **补码数截断**：先按无符号取模保留低 $k$ 位，再按 $k$ 位补码重新解释。令 $x = B2T_w(\vec{x})$，截断后新值 $x' = B2T_k(\vec{x}')$：

$$
x' = B2T_k(\vec{x}') = U2T_k(x \bmod 2^k)
$$


**示例**（将 4 位数值截断为 $k=3$ 位）：
* 无符号 `1011`（$u=11$）截断得 `011`：$u' = 11 \bmod 8 = 3$。
* 补码 `1101`（$x=-3$）截断得 `101`：$x' = U2T_3(-3 \bmod 8) = U2T_3(5) = -3$（未溢出）；若将 `1011`（$x=-5$）截断得 `011`：$x' = U2T_3(-5 \bmod 8) = U2T_3(3) = 3$（发生溢出）。

# 3. 整数运算

以下模运算描述固定宽度位模式的结果，不意味着 C 有符号溢出是可依赖的行为。

## 3.1 无符号加法与乘法

对 $w$ 位无符号数，加法和乘法都保留低 $w$ 位：

$$
x+_w^u y=(x+y)\bmod 2^w,\qquad x\times_w^u y=(x\times y)\bmod 2^w
$$

无符号加法发生回绕时，结果小于任一加数；可通过 `sum < x` 检查一次加法是否回绕。C 对无符号溢出按模规则定义，不会自动报错。

## 3.2 补码加法

补码加法的低位结果与无符号加法相同，但按补码解释。正溢出时结果变为负数，负溢出时结果变为非负数。若 $x,y$ 同为正而结果为负，或 $x,y$ 同为负而结果非负，则发生补码加法溢出。

C 的有符号溢出属于未定义行为。编译器可以假设有符号溢出不会发生，因此不能依赖硬件回绕结果；需要模运算时应使用无符号类型。

## 3.3 补码取反

补码相反数按位计算为：

$$
-x=\sim x+1
$$

最小补码数 $TMin=-2^{w-1}$ 没有对应的同宽正数，因此在位级回绕中 `-TMin` 仍得到 `TMin`。在 C 中，对最小有符号值求负会造成有符号溢出，不能依赖该结果。

## 3.4 补码乘法

无符号乘法与补码乘法在低 $w$ 位上的位级结果相同；差别在于如何解释结果。补码乘法的数学结果若超出范围，低位会对应模 $2^w$ 的结果，但 C 中有符号溢出仍然是未定义行为。

## 3.5 乘以常数

乘以 $2^k$ 在位级上对应左移 $k$ 位。编译器可能把常数乘法改写成移位、加法和减法的组合。例如：

$$
14x=(x\ll3)+(x\ll2)+(x\ll1)=(x\ll4)-(x\ll2)
$$

选择哪种序列取决于目标处理器、溢出语义和优化目标；现代处理器上的乘法并不一定比移位加法慢，应以生成代码和性能测量为准。

## 3.6 除以 2 的幂

无符号数除以 $2^k$ 等价于逻辑右移 $k$ 位。非负补码数也可以算术右移。负补码数的算术右移通常向负无穷取整，而 C 有符号除法向 0 截断，因此直接右移可能与 `/` 不同。

对于负数，若需要通过右移实现向 0 截断，需先加偏置 $2^k-1$，再算术右移 $k$ 位：

```c
int divide_by_power_of_two(int x, unsigned k) {
    int bias = (x < 0) ? (1 << k) - 1 : 0;
    return (x + bias) >> k;
}
```

此示例只适用于移位量和中间结果均可表示的范围；通用代码应直接使用除法或更宽的无符号运算实现。

# 4. 浮点数

## 4.1 二进制小数

二进制小数可写成 $\sum_i b_i2^i$。只有能够由有限个 2 的幂之和表示的数才能被精确存储；许多十进制小数（例如 0.1）只能近似表示。浮点格式用有限位数在表示范围与精度之间折衷。

## 4.2 IEEE 754 表示

IEEE 754 浮点数采用：

$$
V=(-1)^s\times M\times 2^E
$$

由符号位 $s$、阶码字段和小数字段构成：

| 格式 | 总宽度 | 阶码位数 $k$ | 小数位数 $n$ | 阶码偏置 |
| --- | ---: | ---: | ---: | ---: |
| 单精度 `float` | 32 | 8 | 23 | 127 |
| 双精度 `double` | 64 | 11 | 52 | 1023 |

编码分三类：

1. **规格化数**：阶码字段非全 0、非全 1。$E=e-(2^{k-1}-1)$，$M=1+f$，其中 $f$ 由小数字段给出。
2. **非规格化数**：阶码字段全 0。$E=1-(2^{k-1}-1)$，$M=f$。它提供逐渐接近 0 的表示，最小规格化数与最大非规格化数之间平滑过渡。
3. **特殊值**：阶码字段全 1、小数字段全 0 表示正负无穷；小数字段非零表示 NaN。

正零和负零的位模式不同，但数值比较时相等。无穷可表示溢出结果；NaN 表示未定义或不可表示的数值结果，NaN 与自身比较也不相等。

## 4.3 浮点数的分布

可表示浮点数并非均匀分布：数值越大，相邻浮点数之间的间隔通常越大；接近零处更密集。有限精度意味着舍入误差随运算传播。查看浮点位模式时，不能把它直接当作同值的整数解释。

## 4.4 舍入

IEEE 754 提供多种舍入方向，默认通常为**舍入到最近值，正中时取偶数**。正中时选择最低有效位为偶数的一侧，可以降低大量运算累计产生的系统性偏差。舍入发生在二进制表示上，而不等同于直接对十进制字符串做“四舍五入”。

## 4.5 浮点运算性质

在默认 IEEE 754 舍入下，有限浮点数加法和乘法通常满足交换性，但不保证结合律和分配律，因为每一步都可能舍入。例如，大数与小数相加时，小数可能小到无法改变大数的表示。

浮点加法和乘法对有序数具有单调性，但 NaN、无穷和有符号零需要单独考虑。`1/+0` 得到正无穷，`1/-0` 得到负无穷；无穷相减等特殊运算可能产生 NaN。

## 4.6 C 中的浮点转换

- `int` 转 `float`：范围通常足够，但大整数可能舍入。
- `int` 或 `float` 转 `double`：常见 IEEE 754 实现中可精确表示所有 `float` 值，但较宽整数仍可能舍入。
- `double` 转 `float`：可能舍入，也可能超出目标格式范围。
- `float` 或 `double` 转整数：向 0 截断；若有限值超出目标整数范围，C 行为未定义。转换前应检查范围。

不要假设越界浮点转整数会产生固定的负数或固定机器位模式；结果不能作为错误处理机制。

# 5. 常见问题自查

1. **如何声明固定宽度整数？** 使用 `<stdint.h>` 中的 `int32_t`、`uint64_t` 等类型。
2. **64 位系统上 `long` 一定是 8 字节吗？** 不一定；Linux x86-64 常用 LP64，Windows x64 常用 LLP64。
3. **整数强制转换后位会改变吗？** 同宽度有符号/无符号转换通常保留位模式并改变解释；宽度变化则可能扩展或截断。
4. **负数除以 $2^k$ 为什么不能随意改成右移？** 算术右移通常向负无穷取整，而 C 有符号除法向 0 截断。
5. **补码和无符号运算的位级关系是什么？** 固定宽度加法和乘法保留的低位相同，解释结果时才区分有符号和无符号；C 的有符号溢出仍不能依赖。
6. **浮点转整数有哪些风险？** 小数部分向 0 截断；超出整数范围时行为未定义。

# 本章总结

- 整数表示范围有限；无符号运算的模回绕有定义，有符号溢出不可依赖。
- 类型转换、混合比较、截断和符号扩展会改变程序语义，也是常见安全缺陷来源。
- 浮点数范围大但精度有限；舍入导致运算不满足结合律和分配律。
- 分析数值问题时，要同时检查位宽、类型规则和数学范围。
