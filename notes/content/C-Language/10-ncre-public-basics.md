# NCRE Public Basics NCRE公共基础知识速览

本章是二级考试的紧凑附录，不替代数据结构、软件工程或数据库的系统学习。

## 1. 数据结构与算法

- 数据结构由逻辑结构、存储结构和运算组成。
- 线性结构：元素之间通常是一对一关系，例如线性表、栈、队列。
- 非线性结构：树是一对多，图是多对多。
- 顺序表支持按下标随机访问；链表插入删除已知结点位置时通常不需移动其他元素。
- 栈是后进先出（LIFO），队列是先进先出（FIFO）。
- 二叉树第 `i` 层最多有 `2^(i - 1)` 个结点；满二叉树、完全二叉树定义要能区分。
- 查找和排序题应关注时间复杂度、稳定性、是否需要额外空间。

| 算法 | 平均/典型复杂度 | 关键点 |
| --- | --- | --- |
| 顺序查找 | `O(n)` | 无需有序表 |
| 折半查找 | `O(log n)` | 要求有序且可随机访问 |
| 冒泡/直接插入 | `O(n^2)` | 基础题常考，通常稳定 |
| 快速排序 | 平均 `O(n log n)` | 最坏可为 `O(n^2)`，通常不稳定 |

## 2. 程序设计基础

- 结构化程序设计三种基本结构：顺序、选择、循环。
- 模块化强调高内聚、低耦合；函数接口要清晰、单一职责。
- 自顶向下：先分解问题再实现细节；逐步求精：每一步增加细节。
- 测试用例应覆盖正常值、边界值、异常值和典型路径。

## 3. 软件工程

- 软件生命周期常见阶段：可行性研究、需求分析、概要设计、详细设计、编码、测试、运行维护。
- 需求分析回答“做什么”，设计回答“怎么做”。
- 白盒测试关注内部控制结构；黑盒测试依据功能和规格设计用例。
- 单元测试测模块，集成测试测模块接口，系统测试测完整系统。
- 瀑布模型阶段清晰但变更成本高；原型模型有助于澄清需求；增量模型分批交付。

## 4. 数据库基础

- 数据库系统由数据库、数据库管理系统、应用程序、数据库管理员和用户构成。
- 关系表由行（元组/记录）和列（属性/字段）组成。
- 主键能唯一标识一行且不能为空；外键用于表达表间关联。
- `SELECT` 查询，`INSERT` 插入，`UPDATE` 更新，`DELETE` 删除；`WHERE` 筛选行，`ORDER BY` 排序，`GROUP BY` 分组。
- 实体完整性要求主键唯一且非空；参照完整性要求外键值引用存在的主键或为空（取决于约束）。

## 考试检查表

- 折半查找的前提不是“数据量大”，而是有序且能按下标访问。
- 栈、队列、树、图的逻辑关系不要混淆。
- 需求、设计、编码、测试各阶段职责要能区分。
- 主键、候选键、外键与普通属性的作用要能区分。
