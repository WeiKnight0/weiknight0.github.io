# C Expressions and Conversions 运算符、表达式与类型转换

## 1. 运算符、优先级与结合性

| 类别（由高到低） | 运算符 |
| --- | --- |
| 后缀 | `()`、`[]`、`.`、`->`、`x++`、`x--` |
| 一元 | `++x`、`--x`、`+`、`-`、`!`、`~`、`*`、`&`、`sizeof`、强制转换 |
| 算术与移位 | `*`、`/`、`%`；`+`、`-`；`<<`、`>>` |
| 比较 | `<`、`<=`、`>`、`>=`；`==`、`!=` |
| 位与逻辑 | `&`、`^`、`|`；`&&`；`||` |
| 条件、赋值、逗号 | `?:`；`=`、`+=` 等；`,` |

优先级决定如何分组；同优先级运算符再由结合性决定分组方向。它们**不**规定子表达式的先后求值顺序。

```c
int x;

x = 1 + 2 * 3;       /* 乘法优先，所以先计算 2 * 3。 */
x = 10 - 3 - 2;      /* 减法左结合，所以按 (10 - 3) - 2 分组。 */
```

例如 `f() + g()` 的加法两侧谁先调用未规定；而 `f() && g()` 保证先调用 `f()`。不确定时加括号表达分组，但括号不能人为规定普通运算符两侧的求值顺序。

## 2. 整数除法、取模与自增自减

```c
#include <stdio.h>

int main(void)
{
    int a;
    int b;

    a = 7 / 2;  /* 两个操作数都是 int，商的小数部分被截去。 */
    b = 7 % 2;  /* 余数满足 7 == (7 / 2) * 2 + (7 % 2)。 */
    printf("%d %d\n", a, b);
    return 0;
}
```

输出为 `3 1`。两个整数相除结果仍为整数；只要有一个操作数是浮点类型，才进行浮点除法。

- `++i`：先加 1，再取值。
- `i++`：先取旧值，表达式结束前再加 1。
- 不要在同一表达式中既修改变量又在没有明确时序处读取它，例如 `i = i++ + 1;`；这类表达式行为未定义，不能用于推题。

## 3. 逻辑运算与短路

逻辑真为 `1`，假为 `0`。**短路**是指已经能确定整个逻辑表达式结果时，右操作数完全不执行：不读取、不调用函数，也不产生 `++` 等副作用。只有 `&&` 与 `||` 保证从左到右求值并短路；位运算 `&`、`|`、`^` 不短路。

| 表达式 | 左操作数为真 | 左操作数为假 |
| --- | --- | --- |
| `left && right` | 继续计算 `right`，结果由两者决定 | 不计算 `right`，整个结果为 `0` |
| `left \|\| right` | 不计算 `right`，整个结果为 `1` | 继续计算 `right`，结果由两者决定 |

```c
if (ptr != NULL && ptr->value > 0) {
    /* 左侧确认地址有效后，右侧才允许解引用。 */
}
```

这里不能写成 `ptr->value > 0 && ptr != NULL`，因为左边会先解引用空指针。短路还会跳过副作用：`enabled || ++count` 在 `enabled` 非零时不会执行 `++count`。

## 4. 隐式转换与显式强制转换

赋值、运算和函数调用都可能发生转换。考试中最常见的是整型提升与有符号/无符号混合。

```c
#include <stdio.h>

int main(void)
{
    int a;
    int b;
    double average;

    a = 5;
    b = 2;
    average = (double)a / b;  /* 先把左操作数提升为 double，再做浮点除法。 */
    printf("%.1f\n", average);
    return 0;
}
```

若没有 `(double)`，`a / b` 会先得到整数 `2`，之后才被赋给 `double`。强制转换只能改变当前表达式的计算方式，不能修复溢出、越界或错误的对象类型。

## 5. 条件、赋值与逗号表达式

- `condition ? a : b`：只求值其中一个分支；两个分支的类型需要能协调。
- 赋值表达式有值，`if (x = 0)` 合法但通常是笔误；它给 `x` 赋 0，条件为假。比较应写 `x == 0`。
- 逗号运算符从左到右求值，整体值为右操作数；注意它与函数实参之间的逗号不同。

```c
int i;
int value;

i = 1;
value = (i = i + 1, i * 3);  /* 逗号左侧先递增 i，整个表达式取右侧的值。 */
```

## 6. 位运算的边界

`&`、`|`、`^`、`~`、`<<`、`>>` 用于整数位模式。位移位数不能为负，也不能大于等于类型宽度；对负数左移、带符号右移的细节不应凭直觉猜测。涉及掩码时优先使用无符号常量，例如 `1U << bit`。

## 考试检查表

- 先确认操作数类型，再计算表达式，不要只看变量最终接收的类型。
- `=`、`==`，`&`、`&&`，`|`、`||` 是高频改错点。
- 遇到多个 `++`、函数调用或赋值混在一行，先判断是否有未定义行为；有则不能推出唯一结果。
