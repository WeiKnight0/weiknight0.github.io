# C Exam Pitfalls and Tracing 易错点、程序跟踪与答题方法

## 1. 读程序的固定流程

1. 写出每个变量的类型、初值和有效范围。
2. 先处理声明和赋值，再逐句执行；循环题为每一轮列出循环变量、累加器和数组变化。
3. 对表达式先做类型转换，再按括号、优先级和结合性计算。
4. 出现指针、数组、字符串时先确认对象边界与 `\0`。
5. 若同一表达式中有未规定求值顺序下的多次修改，答案应指出未定义行为，而不是臆测某个编译器输出。

## 2. 高频陷阱速查

| 题面 | 正确判断 |
| --- | --- |
| `if (x = 1)` | 合法但通常是错误；给 `x` 赋值为 1，条件恒真 |
| `5 / 2 * 2.0` | 先整数除法得到 2，结果为 `4.0` |
| `sizeof("abc")` | 为 4，包含末尾 `\0` |
| `strlen("abc")` | 为 3，不包含末尾 `\0` |
| `char s[3] = "abc";` | 初始化空间不足，缺少结尾空字符 |
| `int a[3]; a[3]` | 下标越界，不能当作“第四个元素” |
| `p == NULL` 后 `*p` | 空指针解引用，未定义行为 |
| `free(p); *p = 1;` | 释放后使用，未定义行为 |
| `while (!feof(fp))` | 错误的读文件循环条件 |
| `case variable:` | 非法，`case` 需要整型常量表达式 |

## 3. 指针与数组题的三步法

遇到 `int (*p)[4]`、`int *p[4]` 或 `int a[][4]` 时：

1. 从变量名开始向外读；
2. 先看 `[]` 和 `()`，再看 `*`；
3. 代入“它保存什么地址、解引用后得到什么对象”。

| 声明 | 含义 |
| --- | --- |
| `int *p[4];` | 含 4 个 `int *` 的数组 |
| `int (*p)[4];` | 指向“含 4 个 `int` 的数组”的指针 |
| `int a[3][4];` | 含 3 行、每行 4 个 `int` 的二维数组 |

## 4. 编程题通用模板

### 输入、处理、输出

先明确输入约束，再选择数据表示，最后用样例手算边界：空输入、一个元素、最大值、负数或重复值。

```c
#include <stdio.h>

int main(void)
{
    int n;
    int i;
    int value;
    int maximum;

    if (scanf("%d", &n) != 1 || n <= 0) {
        return 1;
    }
    if (scanf("%d", &maximum) != 1) {
        return 1;
    }
    for (i = 1; i < n; i = i + 1) {
        if (scanf("%d", &value) != 1) {
            return 1;
        }
        if (value > maximum) {
            maximum = value;
        }
    }
    printf("%d\n", maximum);
    return 0;
}
```

这类模板考察：输入是否传地址、循环次数是否为 `n - 1`、最大值是否正确初始化、异常输入是否可处理。

## 5. 常见题型与得分点

| 题型 | 首先检查 | 常见失分 |
| --- | --- | --- |
| 选择/填空 | 类型、优先级、边界 | 将 C++ 规则套进 C |
| 程序填空 | 循环不变量、函数接口 | 下标上界、漏写 `&`、漏写 `return` |
| 改错 | 编译错误、逻辑错误、运行时错误 | 只改语法不检查越界和未初始化 |
| 程序阅读 | 每轮状态表 | 忽略短路与整数除法 |
| 编程 | 输入输出、数据范围、边界 | 只通过样例，未处理 0/1 个元素 |

## 6. 考前最后检查

- 能写出 `for`、`while`、`do-while` 的执行顺序。
- 能解释数组名退化、指针参数、二维数组形参的区别。
- 能区分自动变量、局部静态变量、全局变量和 `extern` 声明。
- 能安全使用 `scanf`、`fgets`、`malloc`、`fopen`，并检查返回值。
- 能识别未初始化读取、越界、空指针解引用、释放后使用、错误格式化输入输出。
- 看到 C99/C11/C23 特性时，先确认题目环境；传统 C90 题不默认支持变长数组、`//` 注释、`long long`、`inline` 或 `for (int i = ...)`。
